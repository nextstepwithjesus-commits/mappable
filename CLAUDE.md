ТЗ: @docs/PLAN.md · промпт реализации: docs/PROMPT.md · состояние работы: docs/progress.md · регламент данных: data/AUTHORING.md
Доработка интерфейса: docs/UI-PROMPT.md · экспертиза и задачи: docs/ui-review/README.md · состояние задач: docs/ui-review/STATUS.md

## Команды
- `npm run -s verse -- "Быт 5:3-5"` — показать стихи; `npm run -s verse -- --find "Мафусал" [--book Быт]` — поиск формы имени
- `npm run -s id -- "Иессей"` — подсказка id
- `npm run -s validate` — все данные; `npm run -s validate -- data/persons/07-judah.json` — один том
- `npm run -s append -- <том.json> <партия.json>` — дописать партию лиц в том
- `npm test` · `npm run -s data` · `npx vite build` · `npm run dev`
- `npm run -s accept` · `npm run -s a11y` · `npm run -s contrast` · `npm run -s coords` — проверки интерфейса, хронологии и раскладки
- снимки для проверки глазами: сценарий в `tools/_*.ts` на основе `tools/ui-kit.ts` (свой порт у каждого агента), снимки — в `.ui-shots/`

## Правила, которые легко нарушить
- IMPORTANT: факты только из 66 канонических книг Синодального перевода, у каждого факта — ссылка на прочитанный стих. Никакого предания.
- Текст в [квадратных скобках] Синодального перевода не является основанием факта.
- Ссылки — в синодальной нумерации и синодальных сокращениях: 1–2 Цар = 1–2 Самуила, 3–4 Цар = 1–2 Царей, Пс — синодальная нумерация.
- Годы в данных исторические: −1010 = 1010 г. до Р. Х., нулевого года нет. Движок считает в астрономических годах.
- Опорное лицо из data/registry.json создаёт только его том-владелец; другие тома ссылаются на id.
- tools/bible/synodal.tsv не редактировать.
- Линии Мессии задаются только в data/lines/*.json; каждый шаг должен подтверждаться связью в данных.
- Дизайн — ТЗ § 5; перед сдачей экрана — проверка по списку § 5.6.
- Каждая правка интерфейса доказывается снимками до и после (tools/ui-kit.ts) или тестом; строка интерфейса не подставляет имя в падеж без склонения.
- Не удалять и не ослаблять тесты ради зелёного результата.
