# «Библия наглядно» — приложение по 66 книгам Синодального перевода

Новое приложение из инструментов: Генеалогия, Время (с «Событиями»), География, Связи, Карточка; главный вход — каталог историй (В-19). Строится с нуля по утверждённым документам; из прежнего атласа «Толедот» (`src/`, `data/`) берутся только данные.

**Начинайте с `docs/app/КАРТА.md`** — где что лежит, что идёт, что ждёт владельца. Правила работы и все решения владельца — `docs/app/00-РЕГЛАМЕНТ.md`; летопись — `docs/app/ЖУРНАЛ.md`; навык ориентации — `navigator`.

## Команды

- `npm run -s find -- "слово"` — поиск по документам, решениям, базе лиц и коду; `--dec В-17`, `--sec 07 8.3`, `--person Давид`
- `npm run -s map` — собрать карту и указатель; `npm run -s docs:check` — проверка документации
- `npm run -s verse -- "Быт 5:3-5"` — стихи; `npm run -s verse -- --find "Мафусал" [--book Быт]` — форма имени (номерные книги без пробела: «1Пар 3:5»)
- `npm run -s base` · `npm run -s base:validate` · `npx vitest run tests/base-*.test.ts` — новая база данных
- `python3 -I docs/app/data/07-цитаты.py <документ>` — цитаты документа есть в своих стихах

## Правила, которые легко нарушить

- IMPORTANT: факты только из 66 канонических книг Синодального перевода, у каждого факта — ссылка на прочитанный стих. Никакого предания.
- Слова в скобках Синодального текста — квадратных и круглых — не основание факта. Исключение — места, которые `tools/bible/brackets.tsv` после ручной сверки с подлинником признаёт текстом: пояснение самого текста (вид «б») и повреждение электронного текста (вид «г»). Факт, которому нужно слово в скобках, записывается только по словам вне скобок и со ссылкой на них; `tools/bible/synodal.tsv` не правится (решение совета по R10, В-17; 02 § 3.8).
- Толкование не становится фактом, ребром, тождеством или годом; понимания — по совету источников (`docs/app/research/R9-авторитеты.md`, Г-1–Г-7).
- Ссылки — в синодальной нумерации и сокращениях: 1–2 Цар = 1–2 Самуила, 3–4 Цар = 1–2 Царей, Пс — синодальная нумерация.
- Годы в данных исторические: −1010 = 1010 г. до Р. Х., нулевого года нет.
- IMPORTANT: интерфейс продукта не реализуется до утверждения документов по инструменту (регламент, обязательное решение владельца).
- Не больше четырёх агентов одновременно (обязательное решение владельца).
- Решения владельца записываются в регламент как `**В-N (дата). Название.**`; пожелания — рекомендации, обязательное помечено «ОБЯЗАТЕЛЬНО».
- IMPORTANT: после каждой вехи — **проверка вехи** (В-20): агент `milestone-checker` (или самопроверка по `docs/app/ПРОВЕРКА-ВЕХИ.md`, если заняты четыре агента); итог — строка в журнале; затем `npm run -s map` и `npm run -s docs:check`.
- Не удалять и не ослаблять тесты ради зелёного результата.
- Пишите владельцу и в документах по-русски, простыми словами; «пометка», не «помета».

Правила для частей проекта — `.claude/rules/` (документы, данные, прототипы, прежний атлас); загружаются при работе с этими файлами.
