# Руководство составителя данных «Толедот»

Этот документ — обязательный регламент для каждого, кто пишет тома `data/persons/*.json`.
Полная модель — `src/data/types.ts`; ТЗ — `docs/PLAN.md`.

## 1. Принципы (нарушение = брак тома)

Почему так строго: атлас будут использовать для учения и проповеди. Одна выдуманная связь подрывает доверие ко всему изданию.

1. **Только канон.** Факты — только из 66 книг. Никаких преданий, апокрифов, Иосифа Флавия, Талмуда, житий. Имён, которых нет в тексте (жена Ноя, жена Каина, родители Марии «Иоаким и Анна»), **не существует** для этих данных.
2. **Основной текст, не скобки.** Слова и числа в `[квадратных скобках]` Синодального текста (вставки по греческому переводу) не являются основанием факта. Если скобка важна (числа Быт 5 и 11, «семьдесят [пять]» душ, Исх 12:40), запишите её: числа — в `born.fatherAgeBracket` / `died.ageBracket`, остальное — в `card.notes` с `kind: "bracket"`.
3. **Синодальные формы и нумерация.** Проверяйте каждое имя и каждую ссылку инструментом (§ 2). Если в разных книгах имя пишется по-разному (Далуиа / Далуия, Раав / Рахава), основной берите форму главного повествования, остальные — в `card.altNames` со ссылками. Имя в `name` — только кириллица.
4. **Каждый факт со ссылкой**, и стих действительно этот факт подтверждает. Проверяющий будет читать стих.
5. **Уровни `cert`:** `scripture` (по умолчанию) — прямо сказано; `inference` — однозначно следует из сопоставления стихов (укажите все стихи); `interpretation` — распространённое, но не единственное понимание (обязательно поясните в `card.notes`).
6. **Тождество лиц (три степени).** *Сказано* («Иероваал, он же Гедеон», Суд 7:1) — одно лицо. *Весомо* (то же имя и та же родня или роль в ту же эпоху) — одно лицо с `card.notes` kind `identification`. *Предположительно* — разные лица, предположение только в `card.notes`.
7. **Родство словами Писания.** Если Писание называет родство без родителей («братья Его», «родственница», «племянник»), запишите `kin` с синодальным термином **дословно** в `rel`, не выводя родителей. Разные вероисповедные понимания перечислите в `card.notes` kind `interpretation`, не выбирая одно. Исключение — **структурный вывод внутри одного родословного перечня**, где иное прочтение не предлагается (Быт 4:20–22: «Ада родила Иавала… Имя брату его Иувал»): тогда родители указываются с `parentCert: "inference"` (или `motherCert`, если выведена только мать), а `kin` с термином текста сохраняется. Если родство оспаривается (братья Господни; сёстры Давида при 2 Цар 17:25) — только `kin`.
8. **Справочный слой.** Написание в подлиннике (`card.original`) и этимология (`card.meaning` без ссылок) — справочные сведения: `meaning` без стихов получает `cert: "interpretation"`. Если синодальная форма следует иному чтению, чем еврейский текст (Аминадав вместо Авинадава), отметьте это в `card.original.note`.
9. **Цитаты** (`card.sayings[].quote`) — дословно из основного текста (валидатор сверяет). Текст в скобках не цитировать.
10. **Нейтральный язык.** Кратко, по-русски, без оценок от себя и без проповеди. Оценки — только пересказом или цитатой оценки самого Писания («делал угодное в очах Господних», 4 Цар 18:3).
11. **Типографика:** «ёлочки», длинное тире « — », «г. до Р. Х.».
12. **Каждый факт — в одном разделе.** Место рождения — только `birth.place`; место смерти и погребения — только `death`; `places` — жительство, странствия и прочие места. Должности и сроки — `offices`; события — `events`; откровения, заветы и оценки Писания — `withGod`. Не повторяйте один факт в нескольких разделах.

## 2. Инструменты

```bash
npm run -s verse -- "Быт 5:18-24" "Лк 3:37"        # показать стихи
npm run -s verse -- --find "Мафусал"              # найти форму имени по всей Библии (до 300 стихов)
npm run -s verse -- --find "Иерахмеил" --book 1Пар # поиск в одной книге
npm run -s id -- "Иессей"                          # подсказка id → iessey
npm run -s validate -- data/persons/07-judah.json  # проверить свой том (0 ошибок обязательно)
npm run -s append -- data/persons/07-judah.json /tmp/…/batch-2.json --volume 07 --title "…" --scope "…"
                                                  # дописать партию лиц в том (большие тома пишите партиями по 15–30 лиц)
```

Книги в ссылках — только эти сокращения: Быт Исх Лев Чис Втор Нав Суд Руф 1Цар 2Цар 3Цар 4Цар 1Пар 2Пар Езд Неем Есф Иов

## 3. Файл тома

`data/persons/NN-slug.json`:

```json
{ "volume": "07", "title": "Колено Иудино", "scope": "Руф 4; 1 Пар 2; 4:1–23 …", "persons": [ … ] }
```

Порядок лиц — генеалогический (родитель раньше детей), дети — в порядке рождения / перечисления.

## 4. Идентификаторы

- Латиница, нижний регистр, дефисы: транслит синодального имени (`npm run -s id`).
- Опорные лица — **строго** из `data/registry.json`. Лицо из реестра создаёт только его том-владелец (`owner`);
  остальные тома только ссылаются на его id. Создавать своё лицо с тем же человеком под другим id — запрещено.
- Имя встречается в Библии у нескольких лиц → добавьте уточнение: `-syn-<отец в род. п.>` (`zakhariya-syn-iodaya`),
  `-doch-<отец>`, `-zhena-<муж>`, или отличительное слово (`-prorok`, `-levit`, `-iz-<место>`). Перед созданием
  проверьте, что id свободен: `grep -h '"id": "zakhariya' data/persons/*.json`.
- Лицо, которое существует в другом томе (не из реестра), тоже нельзя дублировать: ищите `grep -l '"name": "Имя"' data/persons/*.json`.

## 5. Поля лица

| Поле | Правило |
|---|---|
| `id`, `name` | см. § 4; `name` — именительный падеж синодальной формы |
| `disambig` | уточнение для одноимённых: «сын Иессея», «пророк», «Лк 3:24» |
| `kind` | `person` (по умолчанию); `people` — народ или род, названный «сыном» в таблице народов (Быт 10: «Лудим», «Иевусей»); `founder` — «отец» города (1 Пар 2:50–51: «Шовал, отец Кириаф-Иарима»); `clan` — род по предку |
| `fatherGap` | `true`, если родословие может пропускать поколения между лицом и отцом (Руф 4:18–22 от Салмона до Вооза; Исх 6:16–20; Мф 1) |
| `unnamed` | `true` для безымянных лиц, если они — важное звено (жена Лота, дочери Лота, дочь Иеффая, дочь фараона — жена Соломона). `name`: «Жена Лота» |
| `sex` | `m` / `f` |
| `father`, `mother` | id; `parentRefs` — стихи, где названо родство; `parentCert` — если не `scripture`; `motherCert` — если уровень для матери иной (отец назван, мать выведена) |
| `fatherKind` | `legal` — только для Иисуса (Иосиф — законный отец) |
| `order` | порядок среди детей отца: 1 — первенец (если сказано) или порядок перечисления |
| `otherParents` | вторая линия происхождения: `by-luke` (Салафиил — сын Нирия по Лк 3:27), `alternative` (Зоровавель — сын Федаии по 1 Пар 3:19), `legal`, `adoptive`, `levirate`, `ancestor` |
| `spouses` | `{ id, kind: wife/concubine/husband, refs, order? }` — достаточно указать на одной стороне |
| `kin` | родство, которое не выражается отцом/матерью/браком: `rel` — отношение ЭТОГО лица к `id` («родственница», «брат», «дядя», «тесть», «племянник») |
| `roles` | из списка в `types.ts` |
| `group` | область полотна из `data/groups.json` (колено, народ, дом) |
| `prominence` | 5 — центральные лица истории спасения (≈ 40 на всю Библию); 4 — главные лица книг, цари, пророки, праотцы колен; 3 — лица с собственным повествованием; 2 — упомянуты с действием или несколькими фактами; 1 — только имя в родословии |
| `chrono` | § 7 |
| `card` | § 6 |

## 6. Карточка: разделы и наполнение

Разделы и номера фиксированы (§ 1–24, ТЗ § 4.3). Заполняйте то, о чём говорит Писание; пустые разделы опускайте.

| § | Поле | Что писать |
|---|---|---|
| 2 | `original` | `{ lang: he/arc/gr, script: "אַבְרָהָם", translit: "Avraham" }` — только если уверены в написании |
| 3 | `meaning` | значение имени; если объясняет само Писание — `refs` и cert `scripture` (Быт 17:5); если по этимологии — без refs, cert `interpretation` |
| 4 | `altNames` | иные формы и имена: `kind` variant/renamed/title/epithet/foreign/patronymic, с `refs` |

| 6 | `parentsNote` | пояснения о родителях сверх `father/mother` |
| 7 | `lineage` | колено, род, народ, происхождение («из колена Вениаминова», Флп 3:5) |
| 8 | `birth` | `place`, `facts` — обстоятельства рождения (год считает движок) |
| 9–12 | `spousesNote`, `childrenNote`, `siblingsNote`, `kinNote` | только дополнения: безымянные дети («родил сынов и дочерей»), число детей, порядок, особенности |
| 13 | `chronoNote` | хронологические указания текста («в тот год, когда умер царь Озия», Ис 6:1) |
| 14 | `met` | подтверждённые текстом встречи с другими лицами: `{ id, refs, text }` |
| 15 | `places` | `{ name, role: birth/residence/travel/death/burial/other, refs }` |
| 16 | `offices` | должности и служения с годами, если известны |
| 17 | `events` | жизнеописание: хронологический список `{ text, refs, age?, year? }`; у главных лиц — 10–30 пунктов |
| 18 | `sayings` | 1–6 ключевых изречений, точные цитаты |
| 19 | `withGod` | откровения, заветы, обетования, молитвы, оценка Писания |
| 20 | `death` | `place`, `facts` (возраст, обстоятельства), `burial` |
| 21 | `messiahNote` | для лиц линий Мессии: особые сведения (опущен у Матфея; «по толкованию…») |
| 22 | `laterMentions` | упоминания в последующих книгах и в Новом Завете |

| — | `silent` | номера разделов, о которых Писание, по вашей проверке, молчит (для лиц значимости ≥ 3): интерфейс напишет «в Писании не сообщается», а не «не составлено» |

Глубина: значимость 5 — все применимые разделы, подробно; 4 — большинство разделов; 3 — основные (5, 7, 15, 17, 23);
1–2 — сколько даёт текст (часто только имя, отец и ссылка — это нормально).

## 7. Хронология (`chrono`)

Движок сам вычисляет годы из связей. Дайте ему **все опоры, которые даёт текст**, и ничего не выдумывайте.

- Год Адама в данных **не задаётся**: движок привязывает всю хронологию к модели (ТЗ § 8.1). Цепочка Быт 5 и 11 задаётся через `fatherAge`.
- `born.fatherAge` — возраст отца при рождении, если назван (Быт 5; 11; 21:5; 25:26; 41:46 + 45:6 и т. п.). Число в скобках рядом — в `fatherAgeBracket`.
  `born.motherAge` — возраст матери (Сарра 90, Быт 17:17).
- `born.offset: { from, years }` — «через N лет после рождения лица X», когда цепочка не прямая (Сала: 35 лет после Арфаксада).
- `born.notAfter: { from, years }` / `born.notBefore: { from, years }` — «родился не позже / не раньше, чем через N лет после рождения X». Так выражаются условия вроде «Кааф пришёл в Египет с Иаковом» (Быт 46:11: не позже Иаков + 130).
- **До Исхода абсолютных годов не ставьте**, если год не выводится от самого Исхода (Моисей −1526, Аарон −1529, Халев −1485 выводятся от Исхода и допустимы). Годы патриархов зависят от выбранной хронологической модели; для них используйте `fatherAge`, `offset`, `notAfter`, `notBefore`, `epoch`.
- `born.year` — только когда год следует из опорной таблицы (§ 7.1) и данных текста (напр., возраст при воцарении).
  Тогда `cert: inference` и `refs` на стих с возрастом.
- `died.age` — прожил лет (Быт 5:5; 25:7); `died.year` — год смерти по таблице (царь умер в конце царствования).
- `reign` — для правителей: `{ over, start, end, years, ageAtStart, refs }` по таблице § 7.1.
- `active: { from, to, refs, note }` — годы, когда лицо заведомо живо: служение пророка по царям («во дни Озии, Иоафама,
  Ахаза и Езекии», Ис 1:1), участие в датированном событии.
- `epoch` — эпоха жизни, если иных опор нет (id из `data/epochs.json`: antediluvian, postdiluvian, patriarchs, egypt,
  exodus, conquest, judges, united, divided, judah-alone, exile, return, intertestamental, christ, apostolic).

Годы: отрицательные — до Р. Х., нулевого года нет.
