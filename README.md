# Толедот — звёздный атлас библейских родословий

Интерактивная карта родословий всей Библии. Каждое лицо Писания — звезда в год своего рождения; роды и колена — созвездия; две линии к Иисусу Христу — по Матфею (через Иосифа) и по Луке (традиционно — через Марию) — сплетённые ленты золота и лазури. У каждого лица — карточка из 24 разделов в неизменном порядке.

Единственный источник — канон из 66 книг в Синодальном переводе. Чтения в квадратных скобках (вставки по греческому переводу) основанием фактов не служат; они питают только альтернативную хронологическую модель и показываются в примечаниях.

## Как открыть атлас на своём компьютере

Атлас работает целиком на вашем компьютере: без сервера, без сети и без внешних сервисов. Никакие данные никуда не отправляются.

**Готовый файл.** Скачайте файл `toledot.html` (около 10 МБ) и откройте его двойным щелчком. Подойдёт любой современный браузер: Chrome, Edge, Firefox, Safari или Яндекс Браузер. Интернет не нужен.
- Выбор темы, пропорции неба, ширины областей и рабочий набор браузер запоминает для этого файла. Если перенести файл в другую папку, браузер может считать его новым, и эти настройки начнутся заново.
- Адрес в строке браузера хранит лицо и окно неба. Сохраните его в закладки, чтобы вернуться к тому же виду.

**Из репозитория.** Нужны git и Node.js 22.
```
git clone <адрес вашего закрытого репозитория> toledot
cd toledot
npm ci
npm run -s build:single     # один файл: dist-single/index.html — его можно переименовать и открыть с диска
npm run dev                 # или: атлас на http://localhost:5173 с пересборкой при правке
```

## Что умеет атлас

- **Небо.** Масштаб и сдвиг колесом, щипком и клавиатурой; шкала времени от сотворения до 2040 г., неравномерная по насыщенности или истинная; величина звезды — место лица в повествовании.
- **Карточка.** 24 раздела: имя, подлинник, значение, другие имена, роль; родители, род, рождение; супруги, дети, внуки и правнуки, братья и сёстры, иное родство; эпоха и относительная хронология, современники; места, служение, жизнеописание, слова, «перед Богом», смерть; линии Мессии, упоминания, места Писания, примечания. Для каждого раздела видно, есть ли сведения, молчит ли Писание или раздел не составлен.
- **Разворот.** Две карточки рядом, раздел против раздела.
- **Родство.** Название степени родства по-русски и термином Писания; все пути до кратчайшего + 2.
- **Хронология.** Четыре модели: масоретские числа и 430 лет в Египте; краткое пребывание (215 лет); числа в скобках Быт 5 и 11; «Фарре 70 лет». Хронологические напряжения (например, Левий — Кааф — Амрам — Моисей при 430 годах) показываются со стихами.
- **Эпохи**, **указатель** с атласными координатами, **синопсис** родословий (Быт, Руф, 1 Пар, Мф, Лк), **чтение родословных глав** со ссылками на карточки, **сквозной раздел** (один раздел у группы лиц), **условные знаки**, **о карте**.
- **Рабочий набор.** «Взять в работу» — лицо, его семью, предков или потомков на нужное число поколений; переключатель неба «все лица | набор» показывает только их. Набор можно передать ссылкой: у получателя он откроется для просмотра и не заменит его собственный. Потомков и созвездия можно свернуть; открытые карточки лежат стопкой.
- **Масштаб по двум осям.** Время и высота строк растягиваются отдельно; границы между панелью, небом и карточкой перетаскиваются; «небо во весь экран» — клавиша F.
- Ночная и дневная карта (по умолчанию — как тема системы), печать карточки, работа без сети.
- Все клавиши — по «?»; там же одиночные клавиши-буквы можно выключить.

## Команды

```
npm ci
npm run dev                 # разработка
npm run -s validate         # сверка всех данных со стихами Синодального текста
npm run -s data             # хронология и раскладка → src/generated
npm test                    # тесты движка
npx vite build              # сборка сайта в dist/
npm run -s build:single     # один файл для работы с диска без сети (dist-single/index.html)
npm run -s build:artifact   # страница для claude.ai (dist-artifact/); по решению владельца атлас не публикуется
npm run -s accept           # сценарии приёмки в Chromium (около 165; снимки в docs/screens)
npm run -s a11y             # доступность экранов: стол, телефон, планшет (axe-core, WCAG 2.2 AA)
npm run -s shots            # снимки экранов в обеих темах и трёх ширинах
npm run -s perf             # замер на 5 000 синтетических лиц (docs/perf.md)
npm run -s coverage         # покрытие родословных отрывков (docs/coverage.md)
npm run -s contrast         # контраст и различимость лент при нарушениях цветового зрения
npm run -s coords           # стабильность координат опорных звёзд
```

## Устройство

- `data/persons/NN-*.json` — двадцать томов данных; `data/registry.json` — неизменные id опорных лиц; `data/lines/` — две линии Мессии; `data/epochs.json`, `data/anchors.json` — эпохи и внебиблейские опоры хронологии; `data/AUTHORING.md` — регламент составления.
- `src/engine` — хронология (мягкий решатель ограничений), раскладка неба, ленты, масштаб времени, родство, поиск.
- `src/render` — отрисовка неба на Canvas 2D; `src/ui` — интерфейс (Preact).
- `tools/` — валидатор, сборка данных, проверки, снимки, замеры.
- `docs/PLAN.md` — техническое задание; `docs/PROMPT.md` — задание на реализацию; `docs/DESIGN.md` — дизайн; `docs/progress.md` — ход работы.
