# Библия наглядно

Приложение для наглядного изучения Библии по 66 книгам Синодального перевода: каталог всех историй — главный вход; инструменты Генеалогия, Время, География, Связи и Карточка каждого действующего лица. Каждый факт — со ссылкой на стих; предания нет.

- Правила проекта: [`CLAUDE.md`](CLAUDE.md); регламент и решения владельца: [`docs/app/00-РЕГЛАМЕНТ.md`](docs/app/00-РЕГЛАМЕНТ.md).
- Как вести работу с агентами: [`docs/app/ПОРЯДОК-КООРДИНАТОРА.md`](docs/app/ПОРЯДОК-КООРДИНАТОРА.md).
