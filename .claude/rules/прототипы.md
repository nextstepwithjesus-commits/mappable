# Прототипы

- Прототип, показанный владельцу или людям как образ продукта, делается по утверждённой дизайн-системе (документ 08) и до показа проходит проверку арт-директора и специалиста по доступности. Иначе он прямо называется «серый макет: проверяет только путь» (В-19).
- Данные — настоящие из `base/`; каждый факт со стихом; где данных нет — пометка «эскиз».
- До сдачи: снимки на 1280×800 и 360×640 в обеих темах, просмотр глазами, проверка цитат, клавиатуры и контраста.
- Код продукта (`src/`) не трогать и в продукт ничего не переносить.
- Строка интерфейса не подставляет имя в падеж без склонения: либо форма из данных в нужном падеже, либо построение фразы без падежа («Отец: Иессей»). Правило переходит в документ 08 «Дизайн-система» (руководство по словам интерфейса).
