# Документы приложения

Правило загружается всегда (без `paths`): почти вся работа идёт в `docs/app`, а правило с `paths` не загружается при чтении через `find`, Grep или несколько файлов сразу (рецензия навигации, № 4).

- Порядок: исследование → черновик → панель из 4+ рецензентов (`.claude/agents/*-reviewer.md`) → исправление → утверждение владельцем (регламент § 6–7, В-19). До утверждения на документ не опираются.
- Номера документов — по таблице регламента § 7: 04 «Время», 05 «География», 06 «Связи», 08 «Дизайн-система», 11 «Истории». Проверка — `npm run -s docs:check`.
- У каждого документа первая строка после заголовка — `**Статус:** …`; у рецензии в конце — ответ составителя таблицей.
- Пишите по-русски, простыми короткими предложениями; слово «пометка», не «помета».
- Каждый факт — со стихом; цитаты проверяет `python3 -I docs/app/data/07-цитаты.py <документ>`; числа — скриптом `docs/app/data/NN-числа.py`, не на глаз.
- После вехи — журнал, «Сейчас» в карте, `npm run -s map` (навык `navigator`).
