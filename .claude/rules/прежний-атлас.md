# Прежний атлас «Толедот»

- Это прежний продукт; новое приложение строится с нуля, отсюда берутся только данные (регламент). Без поручения владельца здесь ничего не менять.
- ТЗ прежнего атласа — `docs/PLAN.md`; дизайн — его § 5; перед сдачей экрана — проверка по § 5.6.
- Каждая правка интерфейса доказывается снимками до и после (`tools/ui-kit.ts`) или тестом; строка интерфейса не подставляет имя в падеж без склонения.
- Проверки: `npm run -s accept`, `npm run -s a11y`, `npm run -s contrast`, `npm run -s coords`.
