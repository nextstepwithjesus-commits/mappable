# Данные

- Новая база `base/` собирается командой `npm run -s base` из `data/` и шагов правки; руками `base/` не править.
- Каждая правка — шаг в `tools/base/corrections*.ts` с объявленной областью (`scope`); тест проверяет, что шаг меняет только свою область.
- После правки: `npm run -s base:validate` (0 ошибок), `npx vitest run tests/base-*.test.ts`; затем второй ключ — независимый рецензент.
- Скобки: только через `tools/bible/brackets.tsv` и `scriptureText` (`tools/base/brackets.ts`); `tools/bible/synodal.tsv` не редактировать.
- Толкование не становится ребром, тождеством или годом (R9, Г-5); тесты не ослаблять.

## Прежние данные `data/` (источник новой базы)

- Опорное лицо из `data/registry.json` создаёт только его том-владелец; другие тома ссылаются на id.
- Линии Мессии задаются только в `data/lines/*.json` (в новой базе — `base/lines/`); каждый шаг подтверждается связью в данных.
- Годы в данных исторические (−1010 = 1010 г. до Р. Х., нулевого года нет); движок считает в астрономических годах и переводит только для показа.
- Команды прежних данных: `npm run -s validate` (все тома) или `npm run -s validate -- data/persons/07-judah.json`; `npm run -s id -- "Иессей"` — подсказка id; `npm run -s append -- <том.json> <партия.json>`; `npm run -s data` — сборка прежнего атласа. Регламент составления — `data/AUTHORING.md`.
