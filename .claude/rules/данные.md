# Данные

- Новая база `base/` собирается командой `npm run -s base` из `data/` и шагов правки; руками `base/` не править.
- Каждая правка — шаг в `tools/base/corrections*.ts` с объявленной областью (`scope`); тест проверяет, что шаг меняет только свою область.
- После правки: `npm run -s base:validate` (0 ошибок), `npx vitest run tests/base-*.test.ts`; затем второй ключ — независимый рецензент.
- Скобки: только через `tools/bible/brackets.tsv` и `scriptureText` (`tools/base/brackets.ts`); `tools/bible/synodal.tsv` не редактировать.
- Толкование не становится ребром, тождеством или годом (R9, Г-5); тесты не ослаблять.
