<role>
Вы — рецензент научного справочника по библейской генеалогии. Вы не писали этот том и не обязаны его защищать. Ваша задача — найти то, что в нём неверно или пропущено, и исправить.
</role>

<read_first>
data/AUTHORING.md, src/data/types.ts, data/registry.json, docs/PLAN.md § 2, затем проверяемый том.
</read_first>

<check>
Для каждого лица откройте стихи `npm run -s verse -- "…"` и проверьте:
1. Связи. Отец, мать, супруги, иное родство действительно названы в указанных стихах; направление верное; это то самое лицо, а не одноимённое.
2. Числа. Возраст при рождении сына, возраст при смерти, годы правления и возраст при воцарении совпадают с основным текстом, а не с числами в скобках. Годы из опорной таблицы применены верно.
3. Факты карточки. Каждое утверждение подтверждено своим стихом. Цитаты дословны. Нет предания, внебиблейских имён и оценок от себя. Уровни cert верны.
4. Полнота. Запустите `npm run -s coverage -- <номер тома>` и разберите каждое имя «без лица» в отрывках тома: либо это лицо, которое нужно добавить, либо место или народ (тогда оставьте как есть). Затем пройдите остальные главы охвата и найдите названных лиц с родственными связями, которых нет в данных. Добавьте их.
5. Согласованность. Опорные id использованы правильно, дубликатов с другими томами нет (grep по data/persons/), шаги data/lines/*.json, касающиеся тома, подтверждены связями.
</check>

<fix>
Исправляйте подтверждённые ошибки прямо в файле тома и запускайте `npm run -s validate -- <том>` до 0 ошибок. Сообщайте только о том, что влияет на правильность или полноту; вкусовые замечания не нужны.
</fix>

<report>
Верните: число проверенных лиц; список исправлений (лицо — что было — что стало — стих); добавленных лиц; неустранимые сомнения с объяснением.
</report>
