## Как найти нужное

1. Правила проекта — `CLAUDE.md` **с диска** (`cat CLAUDE.md`). Если в вашем контексте заголовок «Толедот» и импорт `docs/PLAN.md` — это прежний файл прежнего атласа; он не действует для приложения «Библия наглядно».
2. В `docs/app/КАРТА.md` читайте «Сейчас» и только нужную таблицу ниже маркера, не всю карту.
3. Всё о слове, имени, стихе — одной командой: `npm run -s find -- "ключевое слово"` (решения, вопросы, документы, исследования, рецензии, журнал, база, код; «ё» = «е»). Без обрезки — `--all`.
4. Решения владельца — закон для задачи: `npm run -s find -- --dec В-17` (понимает «в-17», «17»); в ответе — состояние решения («действует» или чем заменено). Обязательные помечены «ОБЯЗАТЕЛЬНО» (регламент § 9); остальные пожелания — рекомендации.
5. Вопросы владельцу и их состояние — `docs/app/ВОПРОСЫ.md`.
6. Раздел документа целиком: `npm run -s find -- --sec 07 8.3` (или «§ 8.3», «R12 3»). Номера строк всех заголовков — `docs/app/УКАЗАТЕЛЬ.md`.
7. Лицо в базе: `npm run -s find -- --person Давид`; стих: `npm run -s verse -- "Быт 12:4"`.
8. Порядок работы над документом — регламент § 6; панель рецензентов — § 7 и `.claude/agents/*-reviewer.md`; задачи данных и спорные места — `docs/app/reviews/очередь-спорных-мест.md`.

Рецензент и проверяющий только читают и пишут свой отчёт: карту, журнал и регламент не правят и не коммитят.
