# Навигация по проекту

## В начале задачи

1. Прочитайте `docs/app/КАРТА.md` целиком: раздел «Сейчас» (что идёт, что ждёт владельца, долги) и таблицы ниже маркера.
2. Найдите всё, что касается задачи, одной командой: `npm run -s find -- "ключевое слово"` (ищет по решениям, документам, исследованиям, рецензиям, журналу, базе лиц и коду; «ё» = «е»).
3. Решения владельца — закон для задачи: `npm run -s find -- --dec В-N` для каждого найденного В-N. Обязательные помечены «ОБЯЗАТЕЛЬНО»; остальные пожелания — рекомендации (регламент § 9).
4. Нужный раздел документа читайте целиком: `npm run -s find -- --sec 07 8.3`. Номера строк всех заголовков — `docs/app/УКАЗАТЕЛЬ.md`.
5. Лицо в базе: `npm run -s find -- --person Давид`; стих: `npm run -s verse -- "Быт 12:4"`.

## После вехи

Веха — решение владельца, принятая рецензия, новая редакция документа, этап данных, исследование, прототип, новое правило или инструмент.

1. Строка в `docs/app/ЖУРНАЛ.md` под сегодняшней датой, сверху: `- ЧЧ:ММ — что произошло. Где: путь или коммит. Что дальше.` Решение владельца — со ссылкой на В-N.
2. Обновите раздел «Сейчас» в `docs/app/КАРТА.md` (выше маркера): что идёт, что ждёт владельца, следующие шаги, долги; дата обновления.
3. Решение владельца сначала записывается в `docs/app/00-РЕГЛАМЕНТ.md` как `**В-N (дата). Название.**` — номера подряд.
4. `npm run -s map`, затем `npm run -s docs:check` — ноль ошибок.
5. Проверка вехи (В-20): агент `milestone-checker` или самопроверка по `docs/app/ПРОВЕРКА-ВЕХИ.md`; итог — строка в журнале.
6. Закоммитьте карту, указатель и журнал вместе с работой.

## Чего не упустить

- Вопросы владельцу собираются в «Ждёт владельца»; ответ — сразу в регламент как В-N и в журнал.
- Задачи данных и спорные места — в `docs/app/reviews/очередь-спорных-мест.md`; сделанное помечается «сделано: шаг Cxx».
- Порядок документа — регламент § 6; панель рецензентов — § 7 и `.claude/agents/*-reviewer.md`.
- Не больше четырёх агентов одновременно (обязательное решение владельца).
