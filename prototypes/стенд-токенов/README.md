# Стенд токенов

**Статус:** технический стенд, 11 октября 2026. Не прототип и не облик продукта: одна страница на собранных `tokens/dist/tokens.css`, чтобы задание CI «прототипы» проверяло продуктовые токены — кегли в rem, „Крупнее“ и „Самый крупный“, тёмную тему, плотность, `forced-colors` и axe (рецензия интерфейса на ядро, № 1). Перед показом — `npm run -s tokens`.
