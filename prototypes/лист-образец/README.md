# Лист-образец редакции 3

**Статус:** редакция листа 3.2, 11 октября 2026. Исправлена по повторной проверке ред. 3.1 (разделы «Повторная проверка» в `docs/app/reviews/лист-образец-рецензия-{арт,интерфейс,доступность}.md`) и решениям координатора к ней; до этого — ред. 3.1 по Л-1…Л-11. Лист следует поправкам § 3 решений координатора; сам 08 (ред. 3.2) координатор поправит отдельно. Прототип для команды и рецензентов; код в продукт не переносится. Данные — сборка пробы `dist-data-probe/` (коммит eb6917e, после перенумерации базы: эпохи `era-…`) с плашкой «Данные не проверены: проба» на каждом экране. Лист читает из индекса только лица, рёбра, союзы и линии; поля прочтений и опор (`w`, `cand`, `idt`, `works`, `an-…`) не читает.

## Как запустить

Из корня проекта:

```
npm run -s base:bundle -- --probe              # сборка пробы, если её нет
node prototypes/лист-образец/собрать.mjs       # токены.css, данные.js; сырые значения в CSS; контраст
node prototypes/лист-образец/контраст.mjs      # только контраст: код 1, если пара ниже нормы
node prototypes/лист-образец/снимки.mjs        # снимки и проверки → снимки/проверки.json (около двух минут)
```

Страницы открываются файлом, сервер не нужен: `лист.html`, `главная.html`, `каталог.html` (`?книга=Мк`), `история.html`, `карточка.html`, `настройки.html`. Вверху каждой страницы — тёмная полоса «управление листом (не часть продукта)»: тема, цвет действия, мышь или касание, плотность, три шага размера текста. Для снимков то же задают параметры адреса: `theme`, `action`, `input`, `density`, `text`, `layer`, `age`, `panel=0` (без полосы управления).

Стек — простой статический: HTML, CSS, обычный JS, Node для сборки и Playwright для снимков. Взяты технические выводы проб: подписи схем — HTML поверх линий SVG (П-Т1), уровни истории браузера — замена записи для порядка, фильтров и раскрытий (П-Т5). Облик прежнего листа шага 0 не взят; взяты только приёмы сборки (один файл токенов → CSS, проверка сырых значений, скрипт контраста).

## Файлы

| Файл | Что это |
|---|---|
| `токены.json` | один файл токенов по 08 § 3.1 (W3C Design Tokens 2025.10): основа → роль → компонент; тема, касание, плотность, телефон и цвет действия — режимы одного токена (`$extensions["app.режимы"]`); 125 пар контраста — `$extensions["app.контраст"]` |
| `токены.mjs`, `контраст.mjs` | чтение токенов, ссылки, режимы; формула WCAG 2.x |
| `собрать.mjs` | `токены.css` (основа в CSS не выходит), `данные.js`; ловит сырые цвета, px, rem, ms в `основа.css` и `компоненты.css` (в `лист.css` — только цвета: это подмости листа) |
| `основа.css`, `компоненты.css`, `лист.css` | шкала, голоса, фокус; компоненты § 7; раскладка экранов и листа |
| `общее.js`, `знаки.js`, `образы.js` | настройки до первого кадра, шапка, адреса и стихи, копия с адресом, раскрытия, список-выбор, меню; свой набор значков; малые образы |
| `лист.js`, `главная.js`, `каталог.js`, `история.js`, `карточка.js`, `настройки.js` | лист и пять экранов |
| `снимки.mjs`, `снимки/` | снимки и проверки; `*-весь.png` — вне git |

**Данные.** Лица, союзы, линии Мессии, карточка Ноя и «Библия молчит» — сборка пробы и `base/nodata.json`. Стихи — одна команда `npm run -s verse` (156 стихов); стихи ссылок карточки — из `dist-data-probe/verses/`. Эпохи — `base/epochs.json`. Истории (каталог Бытия, Мк 1–3, страница *Ной и потоп*, сцены *Расслабленного*) — **эскиз**: разметка одного составителя шага 0 (`prototypes/шаг-0/данные/`), второго ключа нет; каталога историй в базе ещё нет, выхода пробы П7 тоже. Пометка «эскиз» — на экранах. Пояснения словаря «ковчег» и «локоть» — черновик шага 0, их проверяют педагог и библеист.
