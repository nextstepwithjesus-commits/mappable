# Лист-образец редакции 3

**Статус:** редакция листа 3.1, 11 октября 2026, к повторной проверке. Исправлена по трём рецензиям панели (`docs/app/reviews/лист-образец-рецензия-{арт,интерфейс,доступность}.md`) и решениям координатора Л-1…Л-11 (`лист-образец-решения-координатора.md`). Лист уже следует поправкам § 3 решений; сам 08 (ред. 3.2) координатор поправит после повторной проверки. Прототип для команды и рецензентов, владельцу как облик не показывается; код в продукт не переносится. Данные — сборка пробы `dist-data-probe/` (коммит 3d6d018) с плашкой «Данные не проверены: проба» на каждом экране.

## Как запустить

Из корня проекта:

```
npm run -s base:bundle -- --probe              # сборка пробы, если её нет
node prototypes/лист-образец/собрать.mjs       # токены.css, данные.js; сырые значения в CSS; контраст
node prototypes/лист-образец/контраст.mjs      # только контраст: код 1, если пара ниже нормы
node prototypes/лист-образец/снимки.mjs        # снимки и проверки → снимки/проверки.json (около двух минут)
```

Страницы открываются файлом, сервер не нужен: `лист.html`, `главная.html`, `каталог.html` (`?книга=Мк`), `история.html`, `карточка.html`, `настройки.html`. Вверху каждой страницы — тёмная полоса «управление листом (не часть продукта)»: тема, цвет действия, мышь или касание, плотность, три шага размера текста. Для снимков то же задают параметры адреса: `theme`, `action`, `input`, `density`, `text`, `layer`, `age`, `panel=0` (без полосы управления).

Стек — простой статический: HTML, CSS, обычный JS, Node для сборки и Playwright для снимков. Взяты технические выводы проб: подписи схем — HTML поверх линий SVG (П-Т1), уровни истории браузера — замена записи для порядка, фильтров и раскрытий (П-Т5). Облик прежнего листа шага 0 не взят; взяты только приёмы сборки (один файл токенов → CSS, проверка сырых значений, скрипт контраста).

Стихи — одна команда `npm run -s verse` (156 стихов); стихи ссылок карточки — из `dist-data-probe/verses/`. Эпохи — `base/epochs.json`. Пометка «эскиз» — на экранах. Пояснения словаря «ковчег» и «локоть» — черновик шага 0, их проверяют педагог и библеист.

3. Порог 1280 × 720: 11 строк при 12 (см. выше).
4. Карты нет (точек мест на диске нет); Связи — строка «мы ещё не написали». Значков рядом с Lucide и образцов отделки (Stripe, Linear, Our World in Data) нет на диске.
5. Матрица компонентов — ключевые компоненты и состояния, не полная матрица по всем осям.
6. Не сделано: импорт CSV в русский Excel и biblatex / CSL в Zotero; запись движения; поиск и переходы в инструменты (лист, а не прототип инструмента). Заметки — `localStorage` и `prompt()`.
