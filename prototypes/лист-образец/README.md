# Лист-образец редакции 3

**Статус:** черновик к проверке, 11 октября 2026. Этап 1 плана 10 (08 ред. 3.2, § 10.1; В-27, поправки В-28, В-29). Прототип для команды и рецензентов. Проверки § 10.3 (арт-директор, доступность, педагог, научные инструменты, интерфейс) ещё не было. Владельцу как облик не показывается. Код в продукт не переносится. Данные — сборка пробы `dist-data-probe/` (коммит 3d6d018) с плашкой «Данные не проверены: проба» на каждом экране.

## Как запустить

Из корня проекта:

```
npm run -s base:bundle -- --probe              # сборка пробы, если её нет
node prototypes/лист-образец/собрать.mjs       # токены.css, данные.js; сырые значения в CSS; контраст
node prototypes/лист-образец/контраст.mjs      # только контраст: код 1, если пара ниже нормы
node prototypes/лист-образец/снимки.mjs        # 66 снимков и проверки → снимки/проверки.json (около минуты)
```

Страницы открываются файлом, сервер не нужен: `лист.html`, `главная.html`, `каталог.html` (`?книга=Мк`), `история.html`, `карточка.html`, `настройки.html`. Вверху каждой страницы — тёмная полоса «управление листом (не часть продукта)»: тема, цвет действия, мышь или касание, плотность, три шага размера текста. Для снимков то же задают параметры адреса: `theme`, `action`, `input`, `density`, `text`, `layer`, `age`, `panel=0` (без полосы управления).

Стек — простой статический: HTML, CSS, обычный JS, Node для сборки и Playwright для снимков. Взяты технические выводы проб: подписи схем — HTML поверх линий SVG (П-Т1), уровни истории браузера — замена записи для порядка, фильтров и раскрытий (П-Т5). Облик прежнего листа шага 0 не взят; взяты только приёмы сборки (один файл токенов → CSS, проверка сырых значений, скрипт контраста).

## Файлы

| Файл | Что это |
|---|---|
| `токены.json` | один файл токенов по 08 § 3.1 (W3C Design Tokens 2025.10): основа → роль → компонент; тема, касание, плотность, телефон и цвет действия — режимы одного токена (`$extensions["app.режимы"]`); 133 пары контраста — `$extensions["app.контраст"]` |
| `токены.mjs`, `контраст.mjs` | чтение токенов, ссылки, режимы; формула WCAG 2.x |
| `собрать.mjs` | `токены.css` (основа в CSS не выходит), `данные.js`; ловит сырые цвета, px, rem, ms в `основа.css` и `компоненты.css` (в `лист.css` — только цвета: это подмости листа) |
| `основа.css`, `компоненты.css`, `лист.css` | шкала, голоса, фокус; компоненты § 7; раскладка экранов и листа |
| `общее.js`, `знаки.js`, `образы.js` | настройки до первого кадра, шапка, адреса и стихи, копия с адресом, раскрытия, список-выбор, меню; свой набор значков; малые образы |
| `лист.js`, `главная.js`, `каталог.js`, `история.js`, `карточка.js`, `настройки.js` | лист и пять экранов |
| `снимки.mjs`, `снимки/` | снимки и проверки; `*-весь.png` — вне git |

**Данные.** Лица, союзы, линии Мессии, карточка Ноя и «Библия молчит» — сборка пробы и `base/nodata.json`. Стихи — одна команда `npm run -s verse` (156 стихов); стихи ссылок карточки — из `dist-data-probe/verses/`. Эпохи — `base/epochs.json`. Истории (каталог Бытия, Мк 1–3, страница *Ной и потоп*, сцены *Расслабленного*) — **эскиз**: разметка одного составителя шага 0 (`prototypes/шаг-0/данные/`), второго ключа нет; каталога историй в базе ещё нет, выхода пробы П7 тоже. Пометка «эскиз» — на экранах. Пояснения словаря «ковчег» и «локоть» — черновик шага 0, их проверяют педагог и библеист.

## Проверки (последний прогон `снимки.mjs`)

- **Снимки:** 66 — шесть страниц × обе темы × 1280 × 720 и 360 × 560; четыре экрана × 1280 × 800 и 360 × 640; варианты § 10.1. Все после загрузки шрифтов; без шрифтов — 0; ошибок JS — 0; горизонтальной прокрутки — 0, в том числе 320 × 256 (400 %).
- **Контраст токенов:** 133 пары, ниже нормы — 0 (худшие: текст 4,64, графика 3,37).
- **Контраст текста по вычисленным стилям** (цвет к ближайшему непрозрачному фону): 0 ниже нормы из 8 532 элементов. Это не замер по пикселям — его на листе нет.
- **axe-core** (wcag2a/aa, 21a/aa, 22aa, `label-content-name-mismatch` включено), 6 страниц × 2 ширины × 2 темы: нарушений 0. `incomplete` — только `color-contrast` (182 узла: текст на полупрозрачных и сгенерированных фонах); вручную не разобраны.
- **Цели:** на мыши меньше 24 px — 0; на касании меньше 44 px — 0 (кнопки и ссылки вне предложений).
- **Копия стиха:** выделение каждого стиха Быт 6:9–22 = показанный текст, скрытых меток нет — 14 из 14. Для `source-issues.tsv` проверена только строка копии (9 совпали, Пс 114:9 — кнопки нет); это слабая проверка: она сравнивает функцию с тем же правилом.
- **Строк каталога на первом экране** (с плашкой пробы): 1280 × 720 — **10 при пороге 12**; 1280 × 800 — 11 при 14; 360 × 560 — **4 при пороге 6**; 360 × 640 — 5 при 8. Плотная: 11 и 4.
- **Шаблонность § 2.6** — пройдена составителем: фон холодный; карточек у однородного нет; крупнее 30 px нет; прописных подписей и «·» в строках нет; стрелок в кнопках, «пилюль», тостов, скелетов, стоковых значков, аватаров, приёмов удержания нет.

## Что не вышло

1. **Пороги первого экрана каталога не выполнены** (10 из 12, 4 из 6). Причины: строка с тихой строкой трудного растёт на 16 px (у Бытия 5 из первых 12 историй трудные); строка выходит 37 px вместо 36; на телефоне переключатель слоя занимает свою строку 44 px.
2. Карты нет: точек мест OpenBible (план, п. 6–7) на диске для листа нет; малый образ Географии — строка-заглушка. Связи — строка «мы ещё не написали».
3. Не сделано руками: остановки VoiceOver на iPhone (п. 11), ручной набор § 6.4, Windows в режиме высокой контрастности (только эмуляция Chromium), Firefox и Safari, разбор `incomplete` axe, запись движения (п. 13), импорт CSV в русский Excel и biblatex/CSL в Zotero.
4. Значки рядом с Lucide (п. 8) и образцы отделки Stripe, Linear, Our World in Data (п. 16) — снимков на диске нет, скачивать не стал.
5. Матрица компонентов — ключевые компоненты в обеих темах, а не полная матрица по всем осям; полная — в каталоге компонентов продукта (08 § 10.1).
6. Заметки — в `localStorage` и через `prompt()`; поиск, переходы в инструменты и «Вся глава» — не работают (лист, а не прототип инструмента).

## Вопросы к 08

1. **Телефон, каталог:** бюджет § 3.4 (56 + 64 + 44 + 32 + 7 × 48) не оставляет места переключателю слоя, а § 7.9 ставит его над содержимым и на телефоне. Где он стоит на телефоне — в строке действий, в «Меню» или порог 6 строк считается без него?
2. **Тихая строка трудного** растит строку (§ 7.24), а пороги § 3.4 посчитаны по строке 36 / 48. Пороги — по строкам без трудного или с учётом доли трудных историй?
3. **Номер главы:** § 3.2.2 п. 0а относит его к цвету действия, а § 2.5 п. 1а, § 3.3.2 и § 3.3.4 — к «чернила-ВЗ/НЗ». На листе — чернила Завета.
4. **Трудная история и первый экран:** § 4.7 п. 3 — первая часть трудной истории не раскрывается сама; § 2.2 и § 3.4 требуют начала текста на первом экране страницы истории. Для *Ной и потоп* выполнить оба нельзя.
5. **Высота заглушки в шапке истории:** при ширине панели 466 px и пропорции 4 : 3 рисунок выше 40 % окна; на листе — 16 : 9. Какая пропорция у места рисунка?
