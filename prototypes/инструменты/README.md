## Как запустить

```
npm run -s proto:build      # пакеты пробы (tools/pack) + данные прототипа + сборка Vite в dist/
npm run -s proto:dev        # или разработка: http://localhost:5190/prototypes/инструменты/dist/
npm run -s proto:test       # поведение и адреса (Vitest + Playwright, три движка)
npm run -s proto:shots      # снимки сцен и замеры → снимки/, опись сцен → истории/сцены.json, время/сцены.json
npm run -s ci:prototypes    # задание CI «прототипы»: axe, Tab, 12 состояний окна на 13 адресах прототипа
```

Параметры адреса только для снимков и проверок: `theme`, `layer`, `text`, `age`, `density`, `input`, `motion`.

## Задачи данных (в `base/` не правилось)

- **Начала царствований с соправлением.** `chrono.reign` в базе начинает царей с соправления (Озия с 792, Факей с 752, Ахаз с 735), и номер года «от начала в базе» не сходится со стихами. Прототип считает год по стиху синхронизма; в данных нужен вход `synchronism` у каждого царя 4 Цар 15–18 (сейчас есть) и отдельные поля начала соправления и единоличного правления у схемы, а не у лица.
- **Форма имени по стиху.** «Азария» (4 Цар 15:1), «Иеровоам, сын Иоасов» (4 Цар 14:23), «Осия, сын Илы» (4 Цар 17:1) прототип берёт из своей таблицы `ИМЯ_В_СТИХЕ`; нужна форма имени со стихом в данных, и «он же Озия» (4 Цар 15:13).
- **События народов** (4 Цар 18:9, 10, 13; Фул — 4 Цар 15:19) — прототип держит своей таблицей; нужны записи событий.
- **`sync.note`** в хронологии: слово «принятой» и заметка о 744 г. (это McFall — Young, не Тиле) — переписать.
- **Таблица `s-mcfall-young`** пуста; у `s-thiele` — «страница не сверена».
- **`seeAlso.text`** у *Давид и Голиаф*: «назван ещё» — переписать по 11 § 4.5 п. 8; на экран прототип эту строку не выводит.
- **Синопсис**: различие «когда» (Деян 22:6; 26:13) — снять; различия «что набрали», «где это было» — с цитатами всех говорящих рассказов (Мф 14:20; Лк 9:17; Мф 14:13; Мк 6:32); точки деления стихов на «а / б» (Лк 9:14; Ин 6:10).

- **Подпись данных.** Записи сцен не подписаны вторым ключом (10 § 4.2.2 «К подписи»); тест описи — красный. До подписи показа владельцу нет.
