# Рабочий прототип пакета 1 «Истории и Время»

**Статус:** рабочий прототип по 10 § 4.2.2, 11 октября 2026 — все 16 сцен показа открываются на данных пакета «проба» (13 готовы, 3 — с пометкой «эскиз»: Исход, вертикальная шкала телефона, годы «Правителей»); бюджет 300 px над первым стихом взят во всех замерах (без плашки пробы); копия выделения цела в Chromium, Firefox и WebKit; тест описи сцен — красный: из 237 ключей сцен вторым ключом подписаны 11 (условие показа владельцу, 10 § 3.3). Готов к панели 08 § 10.3; показ владельцу — после подписи записей сцен и четырёх «принять».

Код в продукт не переносится (09 § 10.1). Данные — пакеты уровня «проба» с плашкой «Данные не проверены: проба» на каждом экране.

## Как запустить

```
npm run -s proto:build      # пакеты пробы (tools/pack) + данные прототипа + сборка Vite в dist/
npm run -s proto:dev        # или разработка: http://localhost:5190/prototypes/инструменты/dist/
npm run -s proto:test       # поведение и адреса (Vitest + Playwright, три движка)
npm run -s proto:shots      # снимки сцен и замеры → снимки/, опись сцен → истории/сцены.json, время/сцены.json
npm run -s ci:prototypes    # задание CI «прототипы»: axe, Tab, 12 состояний окна на 13 адресах прототипа
```

Параметры адреса только для снимков и проверок: `theme`, `layer`, `text`, `age`, `density`, `input`, `motion`.

|---|---|---|

| облик | `общее/основа.css`, `компоненты.css`, `экраны.css` | лист-образец 3.2 (В-31); своё — `прототип.css` |
| экраны Историй | `истории/` | каталог, страница истории, синопсис, глава, Карточка (сцена перехода), главная, «Все истории», параллельные тексты, сравнение, поиск, настройки |

Стек 09: TypeScript (строгий), Vite, Preact и signals. Находка для 09: signals пропускают перерисовку компонента, который сам не читает сигнал; данные, приходящие позже (текст книги, том карточек), должен читать сам компонент — доступ к стихам в прототипе подписывает вызывающего.

## Чего нет и что передать

- **Подпись данных.** Опись сцен: 237 ключей, подписано 11 — нужен второй ключ на 226 записей (10 § 4.2.2 «К подписи»). До этого показа владельцу нет.
- **`tools/pack`**: ядро индекса несёт `stories: []` — прототип собирает истории своим пакетом. Нужна сборка историй в пакет (02 § 8.1, В-30).
- **Нет в данных**: словарь «Что значат слова», «Найдите вместе», даты текста у частей, время историй по сети, ступени значимости, внешние номера (Евсевий, Theographic), толкования по Г-1–Г-7, истории Исх 12–15, таблицы схем царей с изданием и страницей — на экранах это «эскиз» или честная строка.
- **Не сделано в прототипе**: дорожки участников во «Временах» (04 § 4.4), вертикальная шкала телефона (04 § 8.1), «рядом» с Географией, таблица параллелей наборов «Евангелия» и «Царства», полоса 66 книг на главной — только картинка (книги — списком и листом «Книги»), поиск по тексту стихов (индекс П-Т3 не подключён), замеры скорости 09 § 7, работа без сети, CSV и biblatex.
- **Отступления, которые стоит решить в документах**: при открытом синопсисе справка уходит под таблицу, а не в боковой лист (11 § 4.1); на странице с несколькими рассказами подпись группы «Об этом рассказывают …» — имя ряда вкладок, видимо — «и ещё два рассказа» в строке адреса (иначе не помещается бюджет); адрес части в узкой колонке — только в имени кнопки.
- **Для 09 § 4.4.1**: параметры `rasskaz`, `view`, `ot` у истории; `z`, `at`, `grp`, `show` у Времени.
