# Рабочий прототип пакета 1 «Истории и Время»

**Статус:** рабочий прототип по 10 § 4.2.2, исправлен по панели (решения координатора П-1…П-7 и § 2) и по сверке четырёх экспертов, 11 октября 2026 — 16 сцен показа на данных пакета «проба»; «Правители» считаются по стихам синхронизмов (тест в CI); годы до Р. Х. — только во втором слое и с названием модели; снимков 116, в том числе второй слой; задание CI «прототипы» — 0 новых нарушений. Тест описи сцен — зелёный: все записи сцен показа подписаны вторым ключом (10 § 3.3); во всём пакете прототипа подписано 285 из 587. Ручной набор программ чтения (08 § 6.4) не пройден. Сверка: блокирующих замечаний нет. Готов к показу владельцу — см. «Сценарий показа владельцу»; долги до приёмки — в разделе «Долги до приёмки пакета 1».

Код в продукт не переносится (09 § 10.1). Данные — пакеты уровня «проба» с плашкой «Проба данных: записи ещё не проверены вторым ключом» на каждом экране.

## Как запустить

```
npm run -s proto:show       # показ: сборка и браузер на http://localhost:5191/prototypes/инструменты/dist/
npm run -s proto:build      # пакеты пробы (tools/pack) + данные прототипа + сборка Vite в dist/
npm run -s proto:dev        # или разработка: http://localhost:5190/prototypes/инструменты/dist/
npm run -s proto:test       # поведение и адреса (Vitest + Playwright, три движка)
npm run -s proto:shots      # снимки сцен и замеры → снимки/, опись сцен → истории/сцены.json, время/сцены.json
npm run -s ci:prototypes    # задание CI «прототипы»: axe, Tab, 12 состояний окна на 13 адресах прототипа
```

Параметры адреса только для снимков и проверок: `theme`, `layer`, `text`, `age`, `density`, `input`, `motion`.

## Задачи данных (в `base/` не правилось)

- **Начала царствований с соправлением.** `chrono.reign` в базе начинает царей с соправления (Озия с 792, Факей с 752, Ахаз с 735), и номер года «от начала в базе» не сходится со стихами. Прототип считает год по стиху синхронизма; в данных нужен вход `synchronism` у каждого царя 4 Цар 15–18 (сейчас есть) и отдельные поля начала соправления и единоличного правления у схемы, а не у лица.
- **Форма имени по стиху.** «Азария» (4 Цар 15:1), «Иеровоам, сын Иоасов» (4 Цар 14:23), «Осия, сын Илы» (4 Цар 17:1) прототип берёт из своей таблицы `ИМЯ_В_СТИХЕ`; нужна форма имени со стихом в данных, и «он же Озия» (4 Цар 15:13).
- **События народов** (4 Цар 18:9, 10, 13; Фул — 4 Цар 15:19) — прототип держит своей таблицей; нужны записи событий.
- **`sync.note`** в хронологии: слово «принятой» и заметка о 744 г. (это McFall — Young, не Тиле) — переписать.
- **Таблица `s-mcfall-young`** пуста; у `s-thiele` — «страница не сверена».
- **`seeAlso.text`** у *Давид и Голиаф*: «назван ещё» — переписать по 11 § 4.5 п. 8; на экран прототип эту строку не выводит.
- **Синопсис**: различие «когда» (Деян 22:6; 26:13) — снять; различия «что набрали», «где это было» — с цитатами всех говорящих рассказов (Мф 14:20; Лк 9:17; Мф 14:13; Мк 6:32); точки деления стихов на «а / б» (Лк 9:14; Ин 6:10).
- **Карточка Ноя**: «так они всегда перечисляются» — заменить перечнем стихов (Быт 5:32; 6:10; 7:13; 9:18; 10:1); метка «Кого знал» — в 07.
- **Цитата Евр 11:7** в «Где об этом в Библии» — со смыслом, не одно слово «Ной».
- **Названия с подробностями одного Евангелия** (библеист № 4): *Дочь Иаира* (у Мф 9:18 — «некоторый начальник»), *Тёща Симона* (Мф 8:14 — «тещу его», в доме Петровом), *Множество народа у моря* (у Мф 12:15 моря нет), *Расслабленного спускают через кровлю* (у Мф 9:1–8 кровли нет), *Притчи первосвященникам и фарисеям* (у Мк 12:1–12 — «первосвященники и книжники, и старейшины», Мк 11:27). Нужны общие названия без чужих подробностей или своё название у рассказа (11 § 2.7 п. 7, § 11.3 п. 9).
- **Различия синопсиса**: снять «когда» у Савла (на экране уже снято фильтром `различияИстории`); говорящие в «поручении» — полем данных (сейчас таблица `ГОВОРИТ` в `истории/модель.ts`); начало рассказа Деян 22 — с 22:4 или 22:5 (письма, библеист № 12).
- **Члены группы** (`members`): «сыновья Ноя» — Сим, Хам, Иафет (Быт 7:13); сейчас таблица `ЧЛЕНЫ` в `истории/модель.ts`. Фильтр «Лицо» в каталоге их пока не видит.
- **Халев** — вход Д6 «40 лет при посольстве из Кадес-Варни» (Нав 14:7, 10); на экране — строкой из прототипа.
- **Роли и разделы**: Ной в части 4 — «с ним происходит» (Быт 8:1), не «к нему обращаются» (библеист № 18); «Проповедник правды» (2 Пет 2:5) — в «Кто он», поручения — Быт 6:14, 19–21; 7:1–3 (№ 20); вид трудного «смерть в бою» вместо «убийство» (№ 24, 08 § 4.4); упоминание Иак 5:17 — к 3 Цар 17:1, а не к *Вороны кормят Илию* (№ 22); Аарон — «в сороковой год по исшествии» (Чис 33:38) против счёта по возрастам (№ 17).
- **Граница эпох «Два царства / Иудея одна»** стоит на 723 (McFall — Young), а таблица Тиле кончает Осию 722: пока таблица McFall — Young не внесена, годы Тиле на экране — только справкой в листе царя.
- **Словарь «Что значат слова»** для слов из названий сцен: расслабленный, кровля, житие, ковчег, завет, знамение.
- **`seeAlso.name`** — форма имени для строки «Имя … стоит ещё»; **число стиха у вывода** (у Сима вход несёт 502, а число Быт 5:32 «пятьсот» отдельным полем не записано) и **фраза вывода для простого слоя** — прототип держит их своими таблицами `ПРОСТОЙ_ВЫВОД`, `ЧИСЛО_СТИХА` в `время/модель.ts`.
