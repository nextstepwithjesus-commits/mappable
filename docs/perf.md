# Замер быстродействия (NFR-1)

Chromium без аппаратного ускорения в облачном контейнере, 2026-09-25. Команда: `npm run -s perf`.

| Экран | Лиц | Первый кадр неба | Кадров/с при панорамировании | Медиана кадра | 95-й процентиль | Худший кадр |
|---|---|---|---|---|---|---|
| 1440×900 | 5000 | 994 мс | 60.0 | 16.7 мс | 16.7 мс | 16.8 мс |
| 390×844 | 5000 | 1071 мс | 32.0 | 16.7 мс | 66.7 мс | 100.0 мс |

Требование NFR-1 (ноутбук, 5 000 лиц, 60 кадров/с, первый показ < 2,5 с) выполнено: строка 1440×900.

Строка 390×844 — эмуляция телефона с плотностью 3× (холст ограничен двукратной плотностью). Профиль CPU во время панорамирования: около 62 % времени — программная растеризация Chromium (в контейнере нет видеокарты), код атласа — менее 15 %. На устройстве с аппаратным ускорением холста ожидается заметно выше; этот замер нужно повторить на реальном телефоне.
