# Промпт доработки интерфейса «Толедота»

> **Прежний проект «Толедот» (закрыт 9 октября 2026). Это не задание и не правило для нового приложения «Библия наглядно».** Актуальное — `docs/app/КАРТА.md` и `CLAUDE.md`; из прежнего проекта берутся только данные (регламент § 4).

Этот промпт управляет работой Claude Code (Opus 5.5) над интерфейсом атласа после экспертизы 27 сентября 2026 г. Он дополняет основной промпт [docs/PROMPT.md](PROMPT.md): данные, движок и правила источника остаются прежними, меняется интерфейс.

Промпт составлен по рекомендациям Anthropic:
- [Prompting best practices](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices);
- [Prompting Claude Opus 5.5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5-5);
- [Best practices for Claude Code](https://code.claude.com/docs/en/best-practices);
- навык [frontend-design](https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md).

Как он устроен:
- роль, причины каждого требования, разделы в XML-тегах;
- решения по умолчанию, чтобы работа не останавливалась;
- этапы с проверяемыми критериями готовности;
- правила параллельной работы субагентов;
- обязательная проверка глазами: снимок до и после;
- состояние работы — в файлах, чтобы продолжить из нового окна контекста.

**Как пользоваться.** Начните новую сессию Claude Code в корне репозитория и вставьте текст ниже целиком. Чтобы продолжить после перерыва, достаточно блока `<resume>`.

1. Масштаб времени при первом показе — «по насыщенности». Растяжение ограничить до 1 : 6 (сейчас до 1 : 14,7). Неравномерность показать на линейке (E7).
2. Полоса времени остаётся линейной до 2040 г. (ТЗ § 3.4). Пустой участок после 100 г. тонируется, подписи эпох сокращаются.
3. Лица из списков без родства — скопления с сеткой имён, без следов жизни (E2, ТЗ § 3.1).
4. Путь родства через Иосифа — «по закону (Мф 1:16)». Путь по Лк 3 через Марию — «по толкованию» (ТЗ § 3.2).
5. Атласные координаты настоящие: номера столбцов на линейке, буквы полос слева, объяснение в «Как читать карту».
6. «В Писании не сообщается» показывается всегда, одной бледной сведённой строкой. «Раздел не составлен» скрыт. Для § 21 вне линий — «не относится».
7. Панель — колонка сетки. Если небу остаётся меньше 40 % ширины, карточка сворачивается в корешок.
8. Колесо мыши — масштаб у курсора. Тачпад: два пальца — сдвиг, щипок — масштаб.
9. Названия панелей — из ТЗ, под каждым однострочное пояснение. Кнопки карточки — глаголами.
10. Цвета лент — значения ТЗ § 5.2, свечение слабее.
11. Абзац «Кратко» собирается автоматически из данных карточки, без новых фактов.
12. На телефоне касание звезды открывает лист карточки на 104 px (шапка).
13. На традиционные имена («Иосиф Обручник», «Богородица», «Предтеча») поиск отвечает синодальной формой с пометой «в Синодальном переводе — …».
14. Карточка на экранах ≥ 1360 px — 500 px.
15. Атлас живёт локально. Выпуск — один файл HTML без сети и сервера (npm run -s build:single) и запуск из репозитория. Публичных копий нет. Добавлено владельцем 27.09.2026.

17. Рабочий набор лиц сеанса; небо только по набору; родословные и карточки сворачиваются и разворачиваются (J3–J6). Добавлено владельцем 27.09.2026.

<principles>
Эти принципы решают случаи, которых нет в списке задач.
1. Правда прежде красоты. Строка интерфейса либо верна, грамматична и подтверждена данными, либо её нет. Не подставляйте имя в падежную позицию без склонения: начните строку с имени («Самуил — помазал его…»). Глагол согласуется с полом. Оценка всегда помечена как оценка.
2. Небо не прячет то, с чем работает читатель: выбранное лицо, его семью, путь родства, свою рамку. Перелёт и раскладка учитывают панель, карточку, лист, ярусы и органы управления.
3. Всё видимое объяснено, всё нажимаемое выглядит нажимаемым. У каждого знака, линии и надписи на небе есть строка в «Как читать карту» с образцом, нарисованным той же функцией. Три вида органов управления — ссылка, команда, переключатель — во всех состояниях.
4. Одно действие — одно правило:
   — ссылка на лицо везде выбирает лицо и летит к нему, только если его нет на экране;
   — Escape снимает одно видимое состояние;
   — любое действие прерывает перелёт.
5. Всё строится на системе: токены цвета, восемь кеглей, три вида органов управления, одна функция перелёта, одна функция русской типографики. Разовые значения в style запрещены.
6. Смелость — в одном месте: небо и две ленты. Всё вокруг тихое, строгое, без теней, скруглений, иконок и декоративных анимаций.
7. Телефон, клавиатура и экранный диктор — полноценные пути. Каждый сценарий приёмки проходится мышью, пальцем и клавиатурой.
8. Честность дат: у точного и оценочного разное начертание. Смерть и последнее упоминание различаются. Придуманной длительности жизни на небе нет.
</principles>

<anti_patterns>
Не используйте шаблоны ТЗ § 5.6. Они названы поимённо, потому что общий запрет лишь меняет один шаблон на другой:
— кремовый или тёплый почти белый фон, терракотовый акцент (сюда же дрейф оранжевой ленты к #E2773C);
— почти чёрный фон с одним кислотным или неоновым акцентом (сюда же мятное свечение ленты Луки);
— газетная вёрстка с волосяными линейками во всё поле, линейка под каждой строкой таблицы;
— одинаковые скруглённые карточки с тенью; градиенты ради украшения;
— подписи прописными над заголовками (прописные разрядкой — только названия созвездий на карте);
— строки через «·» и подписи вида «СЛОВО — фрагмент»;
— моноширинный шрифт, в том числе у kbd;
— стрелка «→», добавленная к тексту кнопки или ссылки;
— нумерация «01 / 02» (номера 24 разделов допустимы);
— одно слово заголовка, выделенное курсивом или цветом;
— «пилюли», тосты, мерцающие скелеты, стоковые иконки, эмодзи, пружинящие анимации.
Шаблоны, которые экспертиза нашла именно здесь; их тоже не допускайте:
— одинаковые серые слова вместо органов управления;
— полупрозрачные плашки поверх карты;
— служебная надпись поверх данных;
— тройная линейка;
— системный «×» поиска;
— обрезанное кольцо фокуса;
— легенда словами вместо образцов;
— строки, собранные подстановкой имени в падеж;
— голые числа из выражений `a && b`.
После первого варианта каждого экрана проверьте, какие шаблоны появились вместо запрещённых, и допишите их в этот список в docs/progress.md.
</anti_patterns>

<verification>
