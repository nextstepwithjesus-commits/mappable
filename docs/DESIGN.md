# План дизайна «Звёздный атлас»

Два прохода по навыку frontend-design: сначала план, затем сверка плана с ТЗ § 5 и со списком шаблонов § 5.6. Всё, что прошло сверку, закреплено в маршруте `#/specimen`.

## Проход 1. План

**Главный предмет.** Небо, на котором каждая звезда — лицо из Писания. Интерфейс вокруг похож на поля напечатанной звёздной карты. Это служебные поля, а не «приложение с карточками».

**Цвет.**

| Токен | Ночь | День | Роль |
|---|---|---|---|
| `--sky` | `#0D1B34` | `#EEF2F6` | небо |
| `--sky-band` | `#11223F` | `#E5EBF2` | эпохи через одну |
| `--sheet` | `#0F2040` | `#F8FAFC` | лист карточки |
| `--ink` | `#E8EEF7` | `#172238` | имена, текст |
| `--ink-2` | `#A9B8CF` | `#43536D` | второстепенный текст |
| `--ink-3` | `#8193B0` | `#56637A` | сетка, подписи шкал |
| `--rule` | `#243A5F` | `#CDD6E1` | линии интерфейса, границы созвездий |
| `--gold-1 → --gold-2` | `#F0C66B → #C9773A` | `#9A6A12 → #8E4A1E` | лента Иосифа |
| `--azure-1 → --azure-2` | `#A8D4FA → #9EDBD0` | `#2B64A8 → #1F7A70` | лента Марии |

Оттенок есть только у двух лент. Выделение, фокус и состояния передаются светлотой и толщиной.

**Шрифты.** Literata — имена на небе, текст листа, цитаты; начертание и размер имени зависят от величины звезды. Jost — названия созвездий прописными с разрядкой (только на карте), числа шкал, элементы управления строчными. Noto Serif Hebrew — только § 2.

Шкала кегля листа: 34/40 имя; 17/26 уточнение (курсив); 16/24 текст; 14/20 заметки; 12/16 номера разделов и подписи полей.

**Композиция (≥ 1024 px).**

```

│ 2500 до Р. Х.        2000             1500             1000             500              │
│А   ·  ✦ Ной ─────────────                       С О З В Е З Д И Е   И У Д Ы            │ лист │
│Б        ≈≈≈≈ коса золота и лазури ≈≈≈≈≈≈≈≈                 ✦ Давид ──────               │  24  │
│В   ·        · Сим ───────────                                                          │ раз- │
│…                                                                                       │ дела │
│ ┌ картуш: Толедот. Атлас библейских родословий; масштаб; ключ ┐                          │      │
├──────────────────────────────────────────────────────────────────────────────────────────┤
│ Сотворение │ Потоп │ Патриархи │ Египет │ … │ Р. Х. │ Церковь ▏сегодня ▏2040  [рамка окна] │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

Лист карточки прилегает к правому краю и не отделён тенью: у него своя плоскость цвета и одна линия края. Выравнивание текста — по левому краю, без выключки. Номера разделов висят на полях слева от текста.

**Принципы.**
1. Каждая точка на небе — лицо из данных. Декоративных звёзд, туманностей и «космических» фонов нет. «Облака» на обзорном масштабе — это плотность настоящих лиц.
2. Цвет несут только ленты. Всё остальное различается светлотой.
3. Структуру держит типографика. Рамок, плашек и теней нет.
4. Одно продуманное движение: звёзды зажигаются по величине при загрузке. Остальное движение — ответ на действие.
5. Слова интерфейса — простые русские слова читателя Библии.

## Проход 2. Сверка с шаблонами

| Риск | Решение |
|---|---|
| Тёмно-синий фон с золотом — частый «космический» шаблон | Нет декоративных звёзд и свечения ради красоты: каждая звезда — лицо, облака — плотность данных. Есть координатная сетка, величины и границы созвездий — язык настоящей звёздной карты |
| Почти чёрный фон с одним акцентом | Фон — насыщенная синева `#0D1B34`, акцентов два, и оба несут смысл (две линии) |
| Кремовая бумага и терракота | В дневной теме — холодная бумага `#EEF2F6`, терракоты нет |
| Прописные надписи над заголовками | Прописные с разрядкой — только названия созвездий на самой карте; в интерфейсе — строчные |
| Метастроки через точку | Паспорт лица — таблица с подписанными полями |
| Моноширинные цифры | Цифры — табличные цифры Literata и Jost |
| Карточки с тенями | Лист — одна плоскость без тени и скругления, разделы — типографикой |
| Нумерация «01/02» | Номера разделов 1–24 — настоящая неизменная последовательность; без нулей впереди |
| Кнопки-«пилюли» | Команды — текстовые ссылки на полях; переключатели — подчёркнутые слова |

Изменено по итогам сверки: убран киноварный цвет рубрик (из черновика ТЗ 1.0), убраны капители в подписях интерфейса, шапка «Толедот» оформлена как надпись на поле карты, а не как панель приложения.
