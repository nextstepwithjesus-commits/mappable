# Карта проекта «Библия наглядно»

**Начинайте отсюда.** Это первая страница для координатора, агентов и владельца: где что лежит, что сейчас происходит, что ждёт решения. Верхняя часть пишется вручную; всё ниже маркера собирает `npm run -s map` из самих файлов, поэтому не устаревает.

## Как пользоваться

| Нужно | Как |
|---|---|
| Найти слово, имя, стих, решение | `npm run -s find -- "Каинан"` — по всем документам, базе и коду; «ё» = «е» |
| Текст решения владельца | `npm run -s find -- --dec В-17` |
| Раздел документа целиком | `npm run -s find -- --sec 07 8.3` |
| Лицо в базе | `npm run -s find -- --person Давид` |
| Все заголовки с номерами строк | [УКАЗАТЕЛЬ.md](УКАЗАТЕЛЬ.md) |
| Что произошло и когда | [ЖУРНАЛ.md](ЖУРНАЛ.md) |
| Правила работы и все решения | [00-РЕГЛАМЕНТ.md](00-РЕГЛАМЕНТ.md) |
| Обновить карту и указатель | `npm run -s map` |
| Проверить документацию | `npm run -s docs:check` |
| Стих Синодального текста | `npm run -s verse -- "Быт 12:4"` (номерные книги без пробела: «1Пар 3:5») |

**После каждой вехи** (решение владельца, принятая рецензия, новая редакция, этап данных, исследование, прототип): строка в [ЖУРНАЛ.md](ЖУРНАЛ.md), правка раздела «Сейчас» ниже, затем `npm run -s map` и `npm run -s docs:check`. Подробно — навык `navigator` (`.claude/skills/navigator/SKILL.md`).

## Агенты, навыки, правила (`.claude/`)

- `a11y-reviewer` — Доступность: проверяет документы, эскизы и прототипы «Библии наглядно» по WCAG 2.2 AA, программам чтения, клавиатуре и телефону.
- `art-director-reviewer` — Арт-директор: требовательно проверяет облик документа, дизайн-системы, эскиза или прототипа «Библии наглядно» на уровне лучших мировых справочных и образовательных продуктов.
- `bibleist-reviewer` — Библеист и хронолог: независимо проверяет документы и данные «Библии наглядно» на верность Синодальному тексту 66 книг, отсутствие предания и честность толкований.
- `data-reviewer` — Данные и производительность: проверяет модель данных, источники, лицензии, скорость и работу без сети в документах «Библии наглядно».
- `genealogy-author` — Составляет один том данных атласа «Толедот» (data/persons/NN-*.json) строго по Синодальному тексту 66 книг. Использовать для каждого тома из ТЗ § 9; один вызов — один том.
- `geography-reviewer` — Историк-географ: проверяет места, отождествления, карты, области и пути в документах и данных «Библии наглядно».
- `ia-reviewer` — Архитектура информации и исследование пользователей: проверяет пути читателя, каталоги, поиск, переходы и планы проверок с людьми в документах «Библии наглядно».
- `milestone-checker` — Быстрая проверка вехи проекта «Библия наглядно» по чек-листу главных требований (В-20) — находит только грубые расхождения, пока их дёшево исправить. Запускать после каждой вехи; работает быстро, отчёт не длиннее 15 строк.
- `pedagogy-reviewer` — Педагог: проверяет понятность «Библии наглядно» ребёнку 6–7 лет и новичку, язык, порядок подачи и честность к тексту в простом слое.
- `scripture-verifier` — Независимо проверяет готовый том данных «Толедот» по тексту Синодального перевода и исправляет найденные ошибки. Запускать после genealogy-author для каждого тома.
- `ui-reviewer` — Интерфейс и типографика справочных страниц: проверяет механику, состояния, слои, телефон и согласованность правил с эскизами в документах «Библии наглядно».
- навык `navigator` — Ориентация в проекте «Библия наглядно» — где что лежит, как быстро найти решение владельца, документ, раздел, лицо базы или стих, и как записать веху в журнал и обновить карту. Используйте в начале любой задачи по проекту, перед ответом владельцу о состоянии работ и после каждой вехи.
