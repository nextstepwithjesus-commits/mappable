# Вопросы владельцу

Единый реестр всех вопросов владельцу. Карта (`КАРТА.md`) показывает открытые вопросы автоматически; `npm run -s docs:check` проверяет реестр.

**Правила:**
- У каждого вопроса — номер ВП-N (подряд, не переиспользуется), источник (документ и раздел), дата, когда задан, состояние и рекомендация команды.
- Состояние — одно из: `открыт` · `ответ: В-N` (ответ записан в регламент) · `снят: причина` · `отложен: куда`.
- Ответ владельца сначала записывается в регламент как В-N, затем здесь меняется состояние.
- Документ или исследование с разделом «Вопросы владельцу» должны иметь хотя бы одну строку здесь (иначе `docs:check` предупреждает).
