# Журнал вех

Летопись проекта: что сделано, что решено, где это лежит. Пишет координатор после каждой вехи — утверждения, решения владельца, принятой рецензии, этапа данных, исследования, прототипа. Новые записи — сверху внутри дня; дни — сверху вниз от нового к старому.

**Формат записи:** `- ЧЧ:ММ — что произошло. Где: путь или коммит. Что дальше.` Одна веха — одна строка, без пересказа документа. Решения владельца — со ссылкой на В-N.

Проверка: `npm run -s docs:check` предупреждает, если журнал старше последнего коммита в `docs/app`.
