# Решения координатора по панели прототипа пакета 1

**Статус:** решения координатора по четырём рецензиям (арт-директор, педагог, научные инструменты, доступность), 11.10.2026; основа для правки прототипа. Библеист и архитектура информации — после правки.

Рецензии: `пакет-1-рецензия-арт.md`, `пакет-1-рецензия-педагог.md`, `пакет-1-рецензия-научные.md`, `пакет-1-рецензия-доступность.md`. Все четыре — «показывать нельзя, после исправлений». Блокирующие приняты все.

## 1. Блокирующие

| № | Откуда | Решение |
|---|---|---|
| П-1 | все четверо («Правители») | Номер года царя считается по стиху синхронизма («в тридцать восьмой год Азарии», 4 Цар 15:8), а не от начала царствования в базе. Каждый синхронизм 4 Цар 15–18 либо выполнен, либо помечен «напряжение» со стихами. Номер года не больше числа лет по стиху. Имя — как в стихе («Азария» в 4 Цар 15). Факия — на месте. Тест в CI: синхронизмы выполнены или помечены. Простой слой — без годов до Р. Х.; во втором слое — годы схемы с названием («по Тиле, справка»), а не «без названной схемы». |
| П-2 | педагог, научные («Жизни», Моисей) | В простом слое нет расчётных годов (04 § 2.1): «1446 г. до Р. Х.» у Моисея — только во втором слое с названием модели. Числа на листе лица — только числа текста со своим стихом: у Авраама — 70 по Быт 11:26 (130 — вывод модели, с подписью «расчёт по модели …»); у Сима — 500 по Быт 5:32 (502 — вывод, с подписью). Модель годов названа. Каинан (Лк 3:36) — по набору прочтений `r-father-sala`. |
| П-3 | арт, педагог («Жизни», знаки) | Знаки 04 § 3.10: засечка «умер» по стиху; у Еноха — «Бог взял его» (Быт 5:24) без засечки смерти; число лет на полосе; отметка потопа; срезанные полосы — со знаком. Экран 1.15 без «строк извинений»: что есть — показано, чего нет — одной строкой «эскиз». |
| П-4 | доступность | «Жизни»: у каждой полосы — текст (лет, стих, «расчёт»), таблица-двойник. Esc на пути README — по 08 § 6.5 (тест). Тёмная тема: выбранная строка — языком выбора 08 § 5.2 (контраст ≥ 3 : 1 для заливки, текст ≥ 4,5 : 1). Главы на 360 видны все. «Правители»: выбор касанием и мышью, имя царя в клетке. |
| П-5 | доступность | CI: включить `label-content-name-mismatch` и разобрать 56 узлов; адреса с выбором — в CI; 320 px и «Самый крупный» — без горизонтальной прокрутки; разобрать ответы axe «нужна проверка» по контрасту (выборка по пикселям). |
| П-6 | арт, научные (синопсис) | Регистр слов из текста, без приведения к строчным; отметка различия — не похожа на ссылку; служебные слова не подчёркиваются; ложное различие «около полудня» / «среди дня» — сравнение по смыслу не делаем, а по словам — после нормализации форм; «рассказ молчит» — только если в рассказе действительно нет; стих, разделённый между сценами, — частями «а / б». |
| П-7 | арт (второй слой) | Снимки второго слоя — для сцен 1.13–1.16 и истории. |

## 2. Серьёзные

- Панель справки и простой слой — без служебных слов («пакет N», «Д6», «опись полноты», номера разделов документов).
- «Черновик» — с пояснением прямо рядом: «Черновик — наше деление на истории и подписи. Текст Библии здесь полный». Плашка пробы — другим словом («проба данных»).
- Строка лица — один образец; без точки после «Бог».
- Боковая панель — без отдельной прокрутки, обрезающей текст; строка о 2 Цар 21:19 — из данных (не по id в коде), обе цитаты, без «назван ещё».
- Карточка Ноя — мера строки, вводная фраза, разделы и метки по 07.
- Телефон: номер стиха не отрывается от слова; переносы; первый экран «Времени» с данными; «Крупнее» шкалы — другим словом («Шире» / «Уже» или «Приблизить»).
- «Как сослаться» — с видом и рассказом; у Времени и синопсиса — тоже; выгрузка CSV для «Жизней» и «Правителей».
- Фокус после «Коротко», End в меню стиха, высокая контрастность у полос.
- Скобки в тексте Библии — пояснение по 08 (один раз, в справке).

## 3. В документы (очередь П-1)

- 08 § 4.4: вопрос о возрасте — «Сколько лет тому, кто будет читать?» или иначе однозначно (педагог № 5); строка «Прочтите сначала сами» — к взрослому.
- 09 § 4.4.1: параметры адреса прототипа.
- Показ пакета владельцу до П-Т6 — с пометкой «ручной набор программ чтения не пройден»: решение координатора — допустимо по 08 § 10.3 (исключение листа-образца распространяется на прототип при честной пометке), если остальные условия выполнены; владельцу сказать прямо.
