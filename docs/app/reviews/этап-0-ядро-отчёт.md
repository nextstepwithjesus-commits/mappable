## 1. Что сделано

### 1.1. Ядро `core/` (п. 1)

| `core/loader.ts` | загрузчик: опись с чужой схемой не читается; приложение выпуска не читает пробу и синтетику; пакет сверяется по sha256; готовность без сети; переход на выпуск только при всех обязательных пакетах |
| `core/queries.ts` | запросы: лицо, родители, дети, супруги, переадресация трёх видов; «нет данных для инструмента» — со стихом из записи «нет сведений» |

| `core/years.ts` | годы без нулевого: перевод в астрономические и обратно, подпись «1010 г. до Р. Х.», ISO для выгрузки |
| `core/books.ts` | 66 книг: синодальные сокращения, коды адреса (`byt`, `1par`, `mk`), разбор ссылок данных |
| `core/paths.ts` | таблица адресов 09 § 4.4.1 и уровень перехода 09 § 4.4.2 (считает ядро, а не экран) |
| `core/verses.ts` | стих из пакета текста: нет стиха (`null`), пустой стих (`""`), отрезки скобок с видом, пометки дефектов |
| `core/search/` | поиск: перенос копией из `prototypes/П-Т3/core/` (адреса, Псалмы, словарь форм, основы, проход по тексту, MiniSearch) |

- **Без DOM и без Node.** У ядра свой `core/tsconfig.json` только с ES2023. Чтение файла и sha256 даёт вызывающий.
- **Перенос поиска (10 § 3.1 п. 4).** Код П-Т3 перенесён без изменения поведения. Изменены только импорты и часы: `performance.now()` → `core/clock.ts`. Тесты пробы перенесены (`tests/core-search.test.ts`, 91 тест). Тест бюджетов из пробы перешёл в тесты сборки. В каждом файле записано, откуда он и что рецензии ещё нет.
- **Из `src/engine/` после проверки.** Из `books.ts` взяты: родительный падеж, Завет, `parseRef`, `verseId`, `compareRefs`. Из `text.ts` — `norm` и `translit`. Тест сверяет их с исходником на тех же входах. Не взяты: `nameMatcher` (09 § 3.5 запрещает его для поиска), `stripBrackets` (снимает только квадратные скобки, а по В-17 скобки решает `brackets.tsv`), `splitParentRefs` и `namesIn` (логика карточки прежнего атласа), `encodeBooks` (индекс прежнего атласа).

### 1.2. Сборка пакетов `tools/pack/` (п. 2)

- `npm run -s pack` — уровень «выпуск» → `dist-pack/`; `npm run -s pack -- --probe [--tsk]` — уровень «проба» → `dist-pack-probe/`.
- Источник — допущенные записи `base/`, одна функция допуска. Для индекса используется `buildIndex` из `tools/base/bundle.ts`. Индекс делится на **ядро индекса** и **указатель инструментов**. Оба пакета обязательные (В-30). Членства идут в пакет Генеалогии.
- **Текст по книгам.** В пакете все 31 170 стихов. Есть отрезки скобок с видом и признаком «текст». Есть пометки дефектов. Отсутствующий стих — `null`, пустой — `""`. Пакета «стихи» нет: текст хранится в одном месте.
- **TSK по книгам.** Собирается только по запросу и только на уровне «проба»: коллекции нет в допуске, блок закрыт до Д-12 (02 § 3.16). Если выпуск просит TSK, сборка падает с ошибкой. Часть должна войти в бюджет и по brotli, и по gzip. Поэтому Пс — две части. Английских слов в пакете нет.
- **Опись.** Схема, номер выпуска, уровень, отпечаток `base/` и sha256 целых файлов, числа по статусам. Каждый пакет описан строкой: имя с отпечатком, sha256, размер, gzip, бюджет, «обязательный». Ещё в описи — источники с SPDX. Рядом лежит `NOTICE.txt`.
- **Бюджеты** — у каждого вида пакета. Проверка идёт по brotli 11: так сжимает статическое хранилище (`--compression gzip` — строже). Размер gzip тоже пишется в опись как верхняя граница; превышение по gzip — только замечание.
- **Детерминизм.** JSON с ключами по порядку. В описи нет времени и коммита. Две сборки подряд дают одни байты (тест).
- **NFC.** Строка базы или пакета не в NFC — ошибка сборки.
- **Папки.** Проба и синтетика не пишутся в папку выпуска, выпуск — в их папки (тест).

### 1.3. Токены `tokens/` (п. 3)

- `tokens/токены.json` — файл листа-образца с правками для продукта. Цвет действия — только киноварь (`#A33A1F` / `#F0957B`); вариант «нет» и пробный токен «чернила-писания-тёмная-проба» сняты. У типографики добавлено `letterSpacing: 0`: без него формат DTCG 2025.10 не проходит проверку Terrazzo.
- **Terrazzo 2.7.1 встал без сложностей.** `npm run -s tokens` (`tools/tokens/build.ts`) пишет resolver DTCG 2025.10 и вызывает Terrazzo. Выход: `tokens/dist/tokens.css` и `tokens/dist/tokens.ts` (значения по режимам для холста, SVG и карты).
- **Модификаторы resolver.** Тема, экран (телефон) и ввод. Плотность и способ ввода сведены в одну ось: у целей есть составное значение «касание·плотная» (44 px), а наложение двух независимых осей дало бы 48.
- **Проверки перед сборкой:** ссылки; шкала ровно 30 · 22 · 18 · 16 · 14 · 12 и соседние ступени не ближе 2 px; кегль не мельче 12; киноварь; 124 пары контраста в обеих темах, ниже нормы — 0; имена переменных не совпадают.
- Правило Terrazzo «kebab-case» выключено: имена с прописными (ВЗ, НЗ, Мф, Лк) взяты из 08.

### 1.5. Синтетика полного размера (п. 6)

`npm run -s pack:synth` → `dist-pack-synth/`. Состав:

Всё в бюджете по brotli. Обязательные пакеты вместе — 324,3 КБ brotli. Вся синтетика — 3 473 КБ brotli, 4 296 КБ gzip, 21,3 МБ без сжатия.

**Ядро индекса — на краю: 194,8 из 200 КБ по brotli, а по gzip 263,6 — сверх бюджета.** Из чего оно состоит (brotli / gzip, КБ):

| Часть | brotli, КБ | gzip, КБ |
|---|---|---|
| лица (10 000) | 80,9 | 107,6 |
| словарь форм | 69,2 | 97,3 |
| каталог историй | 36,6 | 44,3 |
| места | 10,4 | 12,5 |

10 000 лиц и словарь форм без отбора по тексту — верхняя оценка. На настоящих данных словарь сейчас 21,9 КБ. Если хранилище будет отдавать только gzip, ядро индекса на полном объёме не войдёт. Это решит выбор хранилища (п. 5 этапа 0). Запасные ходы: имена лиц без значимости 1 — в указатель; словарь форм — только формы из текста.

На пробе (настоящие данные, черновики) всё в бюджете. Ядро индекса — 60,5 КБ, указатель — 55,2, наибольший TSK — Ис, 59,2 (Пс — две части по 50,2 и 52,7 КБ gzip). Замечание по gzip у одного тома: `08-levi` — 65,7 КБ gzip при 45,6 brotli.

## 5. Чего нет

- Рецензии переноса ядра (данные и интерфейс) — до неё `core/search/` остаётся кодом пробы, перенесённым копией.
- Журнала изменений выпуска в новой сборке: `changes.json` пока строит `tools/base/bundle.ts` вместе с записью номера выпуска в `base/redirects.json`. Перенос — отдельным шагом, чтобы сборка пакетов не писала в базу.
- Каталога историй, мест и связей в базе. В настоящей сборке они пустые; размер на полном объёме показывает синтетика.
- «Словарь входа» — поле есть, состав не задан (08 § 4.5, 11).
- Бюджеты Генеалогии и тома Связей — предварительные: 96 КБ. Числа должны дать П-Т4 и 06.
- В задании «прототипы»: «Назад» по 08 § 6.5 и сравнение снимков с эталоном. Снимки пока только складываются в артефакт. Прототипов инструментов ещё нет.
- Файла токенов слов (08 § 3.1), Stylelint, задания «приложение», «скорость» (Lighthouse CI).
- Пакет `minisearch` стал зависимостью проекта. `snowball-stemmers`, `@terrazzo/cli`, `@terrazzo/plugin-css`, `@axe-core/playwright` добавлены как зависимости разработки. Версии закреплены.
