## 1. Что сделано

### 1.1. Ядро `core/` (п. 1)

| Файл | Что |
|---|---|
| `core/types.ts` | типы пакетов и описи. Строки указателя описаны закрытыми типами, у каждого типа — список полей для теста. В карточках есть номер утверждения |
| `core/loader.ts` | загрузчик. Чего он не допускает: опись с чужой схемой; опись без двух обязательных пакетов; выпуск без номера; пробу и синтетику в приложении выпуска; пакет, не совпавший по sha256; вид из многих пакетов без выбора книги или тома. Один файл читается один раз. Текстов книг в памяти — не больше 12. Переход на новый выпуск — только когда все обязательные пакеты на месте |

| `core/refs.ts` | **один форматер адреса** по грамматике 08 § 6.1 п. 16: U+00A0, «–», свёртка списка, «;» без повтора книги, «из». Форма для программы чтения |
| `core/years.ts` | годы без нулевого, U+00A0 в подписи года. Подпись промежутка: «28/29», через эру, «около», «расч.». Счёт «лет от сотворения Адама». Пояснение года для выгрузки |

| `core/paths.ts` | таблица адресов 09 § 4.4.1 и уровень перехода; битая ссылка даёт `null` |
| `core/verses.ts` | стих из пакета: скобки по разметке, дефекты; `showText` — тире вместо дефиса с пробелами |

### 1.2. Сборка пакетов `tools/pack/` (п. 2)

- `npm run -s pack -- --release 2026.10.2` — сборка «выпуск». У выпуска номер обязателен. `npm run -s pack -- --probe [--tsk]` — сборка «проба».
- **Бюджет — одно правило для всех пакетов.** Пока хранилище не выбрано, пакет должен войти и по brotli 5, и по gzip 9.
- **Карточки.** У каждого факта — номер утверждения. Том больше бюджета делится: `08-levi` — на две части, у лица в указателе — номер своей части.
- **Ядро индекса.** Имена лиц — по правилу рецензии № 2, с числом стихов. Имена мест и областей тоже здесь. Словарь форм — из имён лиц и мест. **Уточнения `d` — только в указателе инструментов**: это правило 02 § 8.1 (К-9) на перерасход, решение координатора.
- **NOTICE.** `src-synodal` есть всегда. Приложены полные тексты MIT и OFL 1.1.
- **TSK** — только проба; Пс — две части.

### 1.3. Токены `tokens/` (п. 3)

- Кегли — в rem; проверка сборки ловит px.
- Три оси 08 § 3.1: тема, плотность, ввод, и ещё экран. Составное значение «касание·плотная» снято: касание сильнее плотности.
- Плотный режим по 08 § 3.4: строка инструмента 32, промежуток 8, поля −4. У сенсорного ноутбука — 44.
- Компоненты и цели ссылаются на `основа.размер.*`.
- Добавлены классы окна, отступ прокрутки, признаки шрифта (`onum`, `tnum`, `lnum`). Кегли телефона действуют и по атрибуту области `[data-okno="узкое"]`.
- Сборка — Terrazzo 2.7.1. Стенд `prototypes/стенд-токенов/` показывает `tokens/dist/tokens.css`; CI проверяет на нём „Крупнее“: 18 → 20,25 px.

### 1.5. Синтетика (п. 6)

`npm run -s pack:synth` собирает две синтетики:
- ожидаемый размер, 4 000 лиц — проверяется бюджетами;
- нагрузку, 10 000 лиц — только замер, сборку не роняет.

Общее в обеих: 1 500 историй, 2 182 части; 5 000 связей; 1 342 места сводки OpenBible (имена кириллицей, с формами); 200 областей; словарь входа — оценка, 300 статей. Уточнения — строками базы, с той же долей, что в базе (97 %).
