# Очередь спорных мест

Живого библеиста нет (В-16): самые спорные места решаются по совету опубликованных источников разных традиций (`../research/R9-авторитеты.md`). Сюда координатор записывает места, которые требуют такого разбора. Каждое место — со стихами, нашим решением и вопросом. Пометка в данных — «проверено агентом по источникам».
