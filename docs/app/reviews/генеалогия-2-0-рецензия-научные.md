**Статус:** рецензия прототипа, 12.10.2026. Рецензент научных инструментов. Код и данные не правлены.

RELATION_IS_DESCRIPTOR: «A word or phrase that states object 1's relation is object 2»; пример — `ASSO` у Joe и `RELA great grandson` читается «правнук Joe — это тот, на кого указывает ссылка». ## Что сделано хорошо

- Номер Ahnentafel считается `BigInt` и хранится строкой. У Адама в отчёте Иосифа — 4611686018427387904 (2^62), у Давида — 4294967296 (2^32). Это верно по числу шагов в выбранном прочтении.
- Иисус Христос в «Предках» — одна строка: Мария под номером 3, номер 2 пуст. В GEDCOM Он — ребёнок семьи только Марии; Иосиф — связью `ASSO`, не `FAMC`.
- `FAMC` без `SOUR`; стих связи — у `BIRT`. `MARR` — только при слове брака (111), «наложница» — `EVEN` (10).
- Каинан ни в одном выборе не брат Салы: по умолчанию Арфаксад → Сала, при линии Луки Арфаксад → Каинан → Сала.
- В CSV номер записан со знаком «№», рядом целый столбец «порядок»; архив с `описание.txt`; атрибуция Синодального текста — и в самом `.ged`.
- Сарра в GEDCOM не полнородная сестра Аврама: у неё своя семья с одним Фаррой.
