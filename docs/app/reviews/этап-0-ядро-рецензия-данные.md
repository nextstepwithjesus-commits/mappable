**Статус:** рецензия переноса в ядро (10 § 3.1 п. 4), 11 октября 2026. Предмет — коммит 9c58cf5: `core/` (особенно `core/search/`, перенесённый из `prototypes/П-Т3/core/`), `tools/pack/`, синтетика, бюджеты, CI `.github/workflows/app.yml`; отчёт `docs/app/reviews/этап-0-ядро-отчёт.md`. Мерила: 09 § 4.1–4.2, § 5.3–5.5, § 6, § 8.3, § 16 п. 1–12; 02 § 8. Образцы: Workbox и web.dev «Performance budgets 101» (бюджет — тем сжатием, что реально отдаёт хранилище), STEPBible и Accordance (поиск по лемме, нумерация стихов по таблице), Unicode UAX #15 (NFC на входе, а не только в данных), Lucene (нормализация запроса тем же путём, что индекс).

- **Сборки:** `npm run -s pack`, `npm run -s pack -- --probe --tsk`, `npm run -s pack:synth`. Числа отчёта воспроизводятся: ядро индекса синтетики 194,8 brotli / 263,6 gzip; указатель 129,5; проба: ядро 60,5, указатель 55,2, TSK — наибольший Ис 59,2, Пс две части по 50,2 и 52,7 КБ gzip; словарь форм пробы 21,9 КБ; обязательные вместе 324,3; вся синтетика 3 473 КБ brotli.
- **Перенос `core/search/`:** `diff` с `prototypes/П-Т3/core/` по всем семи файлам. Изменены только заголовки, пути импорта, `performance.now()` → `now()` и добавлен `translit`. Поведение пробы перенесено точно — вместе с её пробелами (ниже).
