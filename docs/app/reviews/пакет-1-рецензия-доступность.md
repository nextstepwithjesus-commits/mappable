# Рабочий прототип пакета 1 «Истории и Время» — рецензия специалиста по доступности

**Статус:** рецензия специалиста по доступности (08 § 10.3 п. 3), 11 октября 2026. Проверена сборка `prototypes/инструменты/dist/` (сборка 11.10, 20:48) на своём сервере localhost. Движки Playwright из кэша: Chromium 1243, Firefox 1538, WebKit 2336. Прототип не правился.

Мерило: шаблоны ARIA APG (Tabs, Menu Button, Treegrid, Data Grid, Disclosure); GOV.UK Design System — фокус после действия и ровно одна область сообщений; синопсис и таблицы STEPBible и Accordance — как читаются ячейки параллельных текстов; таблицы синхронизмов в научных изданиях: у каждой клетки есть имя царя.

## Что работает хорошо

- **Модель «Назад» в основном пути.** История → образ «Время» → выборы → «Назад: Ной и потоп» — фокус на образе, во всех трёх движках. История → Карточка → «Назад» и браузерное «назад» — фокус на строке лица. По ссылке кнопки нет. Esc на экране, открытом по ссылке с выбором, делает `replaceState` и не уводит с сайта.
- **Вкладки рассказов** (*Расслабленного…*): автоматический выбор, стрелки, Home, End, `aria-controls`, `tabpanel` с именем, адрес меняется заменой.
- **Меню стиха:** `aria-haspopup`, `aria-expanded`, фокус на первом пункте, Esc и Tab закрывают и возвращают фокус.
- **Одна область `role="status"` в оболочке** не пересоздаётся. Объявления короткие и без слова «кнопка»: «Выбрано: Адам», «Вид: События», «Выделены стихи Бытие, глава 6, стих 11; …».
- **Кольцо фокуса** 3 px, `:focus-visible` в трёх движках, контраст 12,7–16,4 : 1 в обеих темах (кроме № 3).
- **Скобки** прочитываются как «в скобках: … конец скобок» и не попадают в копию.
- **Контраст текста** без выбора — без нарушений в обеих темах и обоих слоях.
- **Синопсис на 360** без горизонтальной прокрутки; выбор столбцов — флажки с подписями 44 px.

## Чего ждать от программ чтения (по дереву, без устройства)

- **VoiceOver на iPhone, TalkBack.** Свайп по *Ной и потоп*: на каждый стих — два шага («9, кнопка, меню» и текст стиха). До справки при одной открытой части — около 60 шагов, при всех частях — около 180. Ротор «Заголовки» проходит h1 → h2 «Так написано» → h3 частей → h2 справки. В «Жизнях» двойное касание строки откроет лист, но строка прочтётся только именем (№ 1). В «Правителях» двойное касание ничего не делает (№ 4).
- **NVDA и JAWS, режим просмотра.** «Правители» — `role="grid"`: в режиме просмотра стрелки читают клетки «34-й год» без имён (№ 4). «Жизни» — `treegrid`: в режиме просмотра — только имена.
- **Адрес «6:9».** В видимом тексте NVDA двоеточие по умолчанию не произносит. Здесь у кнопки только «Стих 9», а в тексте нет скрытого полного адреса стиха — только «Глава 6.» перед первым стихом. Проверить на устройстве.
