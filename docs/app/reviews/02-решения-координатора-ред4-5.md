# Решения координатора по панели 02 «Данные», редакция 4.5

**Статус:** решения координатора по трём рецензиям (данные, библеист, научные инструменты), 11.10.2026; основа для редакции 4.6.

Рецензии: `02-рецензия-данные-ред4-5.md`, `02-рецензия-библеист-ред4-5.md`, `02-рецензия-научные-ред4-5.md`. Все три — «после исправлений». Блокирующие приняты все.

| № | Откуда | Решение |
|---|---|---|
| Р-1 | научные 1, библеист 1, данные 4 | «Другое написание» больше не даёт уровня «Писание» само по себе: одно ли это имя — суждение о подлиннике. Уровень «Писание» — только когда сам текст связывает два имени (в одном стихе или прямыми словами). Иначе — по общему правилу § 3.3.4: (б) «выв.» при общем родственнике или том же месте, (в) — иначе. Примеры Навин/Нон и Тоах/Тоху — как (б); из примеров «одного имени» убрать. Задача данных: пересмотреть 91 форму «написания». |
| Р-2 | библеист 2 | Неем 12:1–7 и 12:12–21 — не копии одного перечня («во дни Иисуса», 12:7; «во дни Иоакима», 12:12, 26); копия — только Неем 7 / Езд 2 (Неем 7:5). Второй перечень — «из дома X» (Д15-2). |
| Р-3 | данные 1, научные 2, библеист 3 | У опоры — вид: «правитель или событие названы в тексте и датированы внешним документом» (Лк 3:1; синхронизмы с ассирийскими и вавилонскими записями), «расчёт», «предание». `calc.anchor` — только к опорам первого вида; расчёт и предание года не дают. Пример Гал 1:18 снять; пример — Лк 3:1 («в пятнадцатый год правления Тиверия»). У Тиверия — промежуток (счёт от единоличного правления и от соправления), а не один год. |
| Р-4 | научные 3, данные 3 | Различать порядковый год («в сороковой год», Чис 33:38) и срок («спустя три года») — поле вида счёта. Срок `offset` — числом и словами стиха. Опоры: промежуток `{earliest, latest}`, альтернативы — записями, без готовых `derived`; журнал изменений опоры по выпускам, как у модели. Номера `t-` — К-1. |
| Р-5 | данные 2 | Таблица полей входа времени — по коду (`event`, `parts`, `atYear`, `unit`, слова стиха у каждого числа); `end-of-life` — вид входа, не поле `of`. |
| Р-6 | данные 4, библеист 5 | Освобождение заметок от тождества по форме — только по словам («Не смешивать…», «так выходит, если сравнить…») или когда стихи заметки — не стихи формы; не по виду `identification`. Задача данных: 431 заметка вида `identification` без этих слов — разобрать; a-12970 — снять `idCert`. |
| Р-7 | данные 5, библеист 4, научные 4 | Подпись безымянного — поле `descriptor`; из слов стиха; если в подписи имя из соседнего стиха («жена Потифара») — уровень «выв.». Список стихов подписи — полем; «старшая» — Быт 19:31. Покрыть «мать Иеффая», «сын Давида и Вирсавии». Число подписей — пересчитать скриптом. |
| Р-8 | библеист 5 | Мелкие: у Сима годы названы по частям, сумма — вывод; граница «Исход + 40» — Чис 33:38; устаревший пример «он же Азария» — убрать; дубль заголовка § 3.10. |

Остальные серьёзные и мелкие — принять, если не противоречат утверждённому; иначе — в «Ответ составителя».
