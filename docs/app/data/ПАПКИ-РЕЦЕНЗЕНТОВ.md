# Скрипты рецензентов

**Статус:** справка, 9 октября 2026. Перенесены координатором из временной папки сеанса (очередь, долг О-3), чтобы числа рецензий можно было воспроизвести и после переноса проекта.

| Папка | Чья рецензия |
|---|---|
| `03-арт-директор/`, `03-доступность/`, `03-педагог/` | дополнительные рецензии на 03 «Генеалогия» |
| `04-доступность/` | рецензия по доступности на 04 «Время» |
| `05-арт-директор/`, `05-доступность/`, `05-интерфейс/`, `05-географ/` | рецензии и повторная проверка 05 «География» |
| `07-арт-директор/`, `07-педагог/` | дополнительные рецензии на 07 «Карточка» |
| `11-арт-директор/`, `11-доступность/`, `11-педагог/` | рецензии на 11 «Истории» |
| `R12/` | исследование R12 «Каталог историй» |

**Ограничения.** Скрипты писались во временной папке; пути к входным данным в них могут указывать туда (`/tmp/…/scratchpad/…`). Им нужны файлы, которых нет в репозитории: копии OpenBible и Natural Earth, файлы шрифтов Literata и Golos Text, словари символов NVDA. Где их хранить — решается до переноса проекта (долг О-3 в `docs/app/reviews/очередь-спорных-мест.md`). Основные числа документов считают `NN-числа.py` в этой папке.
