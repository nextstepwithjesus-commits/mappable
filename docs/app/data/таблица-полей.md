# Таблица полей переноса (этап Д1)

Документ 02, § 4. Каждое поле прежних данных (`data/`) → место в базе (`base/`) или причина отказа.

- Программа переноса — `tools/base/migrate.ts`.
- Обратная проекция — `tools/base/project.ts`.
- Исправления — `tools/base/corrections.ts`.
- Тест — `tests/base-migrate.test.ts`.

Команда: `npx tsx tools/base/migrate.ts` (`--check` — только проверка, `--verbose` — все отличия).

## Доказательство полноты

1. **Точный перенос без исправлений.** Обратная проекция даёт прежние данные без единого отличия: все 2 684 лица, порядок лиц в томах, обе линии, эпохи, якоря и области. Сравнение — по каноническому JSON: ключи по алфавиту, порядок списков сохраняется.
2. **После исправлений.** Отличается 113 лиц и линия по Луке, и каждое отличие объясняется записанным исправлением (`base/corrections.json`). Поимённый перечень с изменёнными полями — `base/legacy/report.json`.
3. **Подсказки проекции** (`base/legacy/hints.json`) хранят только то, что нужно для побайтной сверки, но не нужно новой модели:
   - была ли степень достоверности родителей записана явно;
   - порядок записей о супругах у каждой стороны;
   - пустые списки;
   - прежние номера переименованных лиц.
