# Таблица полей переноса (этап Д1)

Документ 02, § 4. Каждое поле прежних данных (`data/`) → место в базе (`base/`) или причина отказа. Исправлена по рецензии переноса (`../reviews/Д1-перенос-рецензия.md`).

- Перенос — `tools/base/migrate.ts`; обратная проекция — `tools/base/project.ts`.
- Исправления — `tools/base/corrections.ts`; дополнения — `tools/base/additions.ts`.
- Проверка базы — `tools/base/validate.ts`.
- Тесты — `tests/base-migrate.test.ts`, `tests/base-control.test.ts`, `tests/base-versification.test.ts`.

Команды: `npm run -s base` (перенос; `-- --check`), `npm run -s base:validate`, `npm run -s base:bundle` (сборка для приложения в `dist-data/` с бюджетом и описью). Прямой вызов: `npx tsx tools/base/migrate.ts` (`--check` — только проверка, `--verbose` — все отличия прежнего вида); `npx tsx tools/base/validate.ts` (`--warn` — замечания, `--fresh` — собрать в памяти).

## Доказательство полноты

1. **Точный перенос без исправлений.** Обратная проекция даёт прежние данные без единого отличия: все 2 684 лица, порядок лиц в томах, обе линии, эпохи (с ключевыми лицами и правилами событий), якоря и области. Сравнение — по каноническому JSON: ключи по алфавиту, порядок списков сохраняется.
2. **Исправления — по шагам, по записям.** Каждый шаг объявляет область — какие записи он вправе менять. Перенос применяет шаги по одному и сравнивает **все записи базы** до и после шага: каждое поле лица, каждое поле карточки, каждое ребро, союз, связь, членство, «нет сведений», прочтение, переадресацию, линию, эпоху, состав тома. Изменение вне области — ошибка. Так проверяются и поля, которых в прежних данных не было: прочтения, слова текста, пропуски, сторона и вид союза.
3. **Подложенные искажения ловятся** (тест): перевёрнутая сторона союза, подменённый вид союза, прежний номер в эпохе, шаг вне своей области.
4. **Подсказки проекции** (`base/legacy/hints.json`) хранят только форму, нужную для побайтной сверки:
   - была ли степень достоверности родителей записана явно;
   - порядок записей о супругах у лица (номера союзов; вид и сторону проекция берёт из самого союза);
   - пустые списки;
   - прежние номера переименованных лиц и линий.
5. **Отчёт** — `base/legacy/report.json`: ключи записей, изменённые каждым шагом (C1 — 42, C2 — 4, C3 — 4, C4 — 114, C5 — 1, C6 — 6, C7 — 5, C8 — 8, C9 — 37, C10 — 733, C11 — 34, A1 — 31), и отличия прежнего вида по лицам и полям (763).

## Умолчания

- Нет поля `cert` — «Писание», и в прежних данных, и в базе. `motherCert` по умолчанию равен `parentCert`.
- Номер лица — `p-` + прежний номер; союза — `u-<муж>--<жена>` по прежним номерам; области — `g-` + прежний номер.
- У записей происхождения, союзов, связей, членства, времени и «нет сведений» — `prov.from.vol`: прежний том; коммит прежних данных — у файла.
