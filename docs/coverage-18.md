# Покрытие родословных отрывков

Имя собственное считается сопоставленным, если оно совпадает с именем или иной формой лица, у которого есть ссылка на эту главу.
Итого: 63% имён сопоставлено (66 из 105).


## Чис 1:5-15 — 65% (24 из 37; тома 18)

Без лица: Рувима (1:5); Симеона (1:6); Иуды (1:7); Иссахара (1:8); Завулона (1:9); Иосифа (1:10); Ефрема (1:10); Манассии (1:10); Вениамина (1:11); Дана (1:12); Асира (1:13); Гада (1:14); Неффалима (1:15)

## Чис 13:4-15 — 62% (23 из 37; тома 18)

Без лица: Фаран (13:4); Господню (13:4); Рувимова (13:5); Симеонова (13:6); Иудина (13:7); Иссахарова (13:8); Ефремова (13:9); Вениаминова (13:10); Рафуев (13:10); Завулонова (13:11); Манассии (13:12); Данова (13:13); Асирова (13:14); Неффалимова (13:15)

## Чис 34:19-28 — 61% (19 из 31; тома 18)

Без лица: Иудина (34:19); Иефонниин (34:19); Симеоновых (34:20); Вениаминова (34:21); Дановых (34:22); Иосифовых (34:23); Манассииных (34:23); Ефремовых (34:24); Завулоновых (34:25); Иссахаровых (34:26); Асировых (34:27); Неффалимовых (34:28)
