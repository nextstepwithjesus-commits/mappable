## 3. Десять первоочередных изменений

1. **IX-68.** Поиск и ссылки с обзора приближают к лицу до уровня чтения; щелчок по звезде камеру не двигает.
2. **IX-69.** Набор из ссылки — временный просмотр с «добавить в мой набор».
3. **IX-70.** Вписывание группы не меняет сохранённую пропорцию.
4. **IX-71.** Многословный поиск по имени, уточнению и роли, без ложного «нет в атласе».
5. **IX-72.** Щелчок мимо меню звезды только закрывает меню.
6. **IX-74.** «Назад/вперёд» за 300 мс; адрес — из записи истории.
7. **IX-73.** Выключение «только линий» возвращает окно.
8. **IX-55 (остаток) и IX-75.** Нарицательные «Сын/Дочь/Жена» ищутся только целиком; глава из поиска открывается.
9. **IX-58 (остаток) и IX-77.** Подсказка без строк клавиш, в режиме выбора родство первой строкой; заметная метка набора.
10. **IX-78, IX-79, IX-57 (остаток).** Полоса отвечает сразу; колесо над полосой — ширина рамки ×1,25 у года под указателем; «Всё небо» — 500 мс.

**Почему такой порядок:**
- 1–3 — дешёвые правки (S) на главных путях: небо не откликается на поиск с начального экрана, данные читателя теряются, одно нажатие портит небо навсегда. Их достаточно для 80.
- 4 — правда поиска: атлас не должен говорить «нет», когда лицо есть.
- 5–7 — предсказуемость: закрыть, вернуться, выключить.
- 8–10 — доводка до 90.

## 4. Что работает хорошо (не сломать)

- **Модель хронологии** держит лицо: 0 px во всех четырёх моделях, модель названа в служебной строке.
- **Правая кнопка и клавиши меню:**
  - правая кнопка только открывает меню, подсказки и наведение заморожены;
  - Shift + F10 и клавиша меню открывают то же меню.
- **Перелёты и шаги камеры:**
  - нажатие, колесо и клавиша прерывают перелёт, выбор остаётся;
  - инерция 325 мс, без неё при ослабленном движении;
  - сдвиг стрелками за 180 мс, нажатия складываются.
- **Масштаб:**
  - масштаб у курсора; мышь, тачпад и щипок различаются;
  - пределы с выключением «+ −» и объяснением;
  - отдаление в режиме «набор» — не дальше окна набора;
  - двойной щелчок по звезде ×2 без снятия выбора.
- **Полоса времени:**
  - щелчок внутри рамки ничего не делает, вне — одно движение 400 мс;
  - PageUp и PageDown — по эпохам;
  - у названий курсор `pointer`.
- **Рабочий набор:**
  - «В работе: N»;
  - клавиша В с объявлением, цель — кольцо, иначе подсказка, иначе выбранное лицо;
  - Shift + Enter в поиске и «в работе» в строке результата;
  - строка режима «На небе — только рабочий набор, 2 лица — показать всех».
- **Стопка карточек:** «×» закрывает как вкладку, «Закрыть все», корешок 56 px с «развернуть», двойной щелчок по границе — ширина 500.
- **Выбор второго лица:** путь и «Иессей — отец Давида» при наведении, ряд кнопок не перестраивается.
- **Поиск:**
  - 30–91 мс на символ;
  - «Названы в стихе / главе» и «Стих упомянут в карточке»;
  - щелчок в поле возвращает прежний список;
  - «Руф 4:21» + Enter — Салмон с перелётом.
- **Клавиатура:**
  - небо — 13-я остановка Tab, одна;
  - стрелки ведут кольцо, Enter открывает карточку и ставит фокус на заголовок;
  - цепочка Escape снимает по одному: панель → пара → выбор;
  - «?» назван во вступлении.
- **Адрес:** хранит лицо, окно, панель, пару, модель, режим набора и набор. Перезагрузка возвращает окно. Модель и тема не плодят записей истории.
- **Отзывчивость:**
  - протяжка — p95 16,8 мс на обзоре и у Давида;
  - колесо у Давида — 16,8 мс; на обзоре p95 33 мс, 5 кадров из 85 дольше 33 мс — следить;
  - от щелчка по звезде до карточки — 88–89 мс.

## 5. Вопросы владельцу

1. **Щелчок по звезде на обзоре.** Только выбирать (рекомендация, как в Google Maps) или тоже приближать? Поиск, ссылки и «Показать на небе» по IX-68 приближают в любом случае.
2. **Набор из ссылки.** Временный просмотр с «добавить в мой набор» (рекомендация) или замена своего набора с отменой?
3. **«Назад/вперёд».** Быстрый переход 300 мс (рекомендация) или перелёт, как у ссылок?
4. **Shift + колесо** (вопрос 1 прошлого отчёта, решения по нему нет). Сейчас это растяжение времени, и у мыши без тачпада нет сдвига колесом. Предложение: Shift + колесо — сдвиг по времени, растяжение — Ctrl + Shift + колесо.
5. **Одиночные клавиши-буквы** (E, L, F, D, C, J, K, [ ] , .) работают по всей странице без модификатора. WCAG 2.1.4 требует, чтобы их можно было отключить или переназначить. Добавить переключатель «клавиши-буквы» в таблицу «Клавиши»? (Пересекается с MOB.)

**Не проверено:**
- настоящие колёса и тачпады в Firefox и Safari;
- частота кадров на настоящей видеокарте;
- касания — область MOB.

IX-74 стабильно воспроизводится только на длинной последовательности из девяти шагов; причина (запись адреса по первому кадру перелёта) выведена из кода `address.ts:297-300`.
