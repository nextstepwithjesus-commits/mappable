# Перенос проекта на компьютер владельца

**Статус:** инструкция, 9 октября 2026. Как перенести проект «Библия наглядно» из облачного сеанса Claude Code на свой компьютер (macOS) и продолжить работу там.

## 1. Что переносится

Всё лежит в git, в ветке `claude/bible-genealogy-interactive-map-9b143k` репозитория `nextstepwithjesus-commits/mappable` на GitHub: документы (`docs/app/`), база (`base/`), исходные данные (`data/`), инструменты (`tools/`), скрипты чисел и рецензентов (`docs/app/data/`), входные файлы скриптов (`inputs/`), агенты, навыки, правила и хук Claude Code (`.claude/`). Временная папка облачного сеанса не нужна.

## 2. Что поставить

| Программа | Версия | Как проверить |
|---|---|---|
| git | любая свежая | `git --version` |
| Node.js | 22 (в облаке была 22.22) | `node -v` |
| Python | 3.11 или новее | `python3 --version` |
| Claude Code | последняя | `claude --version` |

На macOS удобно ставить через Homebrew: `brew install git node@22 python@3.11`. Claude Code — по инструкции на сайте Anthropic.

## 3. Скачать проект

```
git clone https://github.com/nextstepwithjesus-commits/mappable.git
cd mappable
git checkout claude/bible-genealogy-interactive-map-9b143k
npm ci
```

## 4. Проверить, что всё работает

Запускать из папки проекта. Все команды должны пройти без ошибок.

| Команда | Что проверяет | Ожидается |
|---|---|---|
| `npm run -s docs:check` | карта, указатель, статусы, решения, реестр вопросов | «ошибок 0» (предупреждения о старых путях — допустимы) |
| `npm run -s base:validate` | новая база данных | 0 ошибок |
| `npx vitest run tests/base-*.test.ts` | тесты базы | все прошли |
| `npm run -s verse -- "Быт 1:1"` | текст Синодального перевода | стих напечатан |
| `python3 -I docs/app/data/07-цитаты.py docs/app/11-ИСТОРИИ.md` | цитаты документа | «не найдено: 0» |
| `python3 -I docs/app/data/05-числа.py` и `08-числа.py` | числа документов по входным файлам `inputs/` | работают без ключей |

## 5. Настроить Claude Code

- Запускать `claude` из папки проекта. Он прочтёт `CLAUDE.md`, правила `.claude/rules/`, агентов и навыки.
- Хук перед коммитом (`.claude/settings.json`) вызывает `python3`; если на компьютере Python называется иначе — поправить там команду.
- В облаке был ещё хук, который требовал коммитить всё перед концом ответа. Он не входит в проект; дома коммит и отправку на GitHub делаете вы или Claude по вашей просьбе.
- Первой командой в новом сеансе — навык `navigator`: он покажет раздел «Сейчас», последние коммиты и итог проверки.

## 6. Что изменится по сравнению с облаком

- Пути `/tmp/…/scratchpad/` в старых скриптах рецензентов (`docs/app/data/*-*/`) больше не существуют; входные данные — в `inputs/`.
- Если на компьютере нет доступа к сети, проверки и скрипты всё равно работают: всё нужное лежит в репозитории.

## 7. Что ждёт после переноса

Перед реализацией нужны ответы владельца на вопросы `docs/app/ВОПРОСЫ.md` и утверждение документов 03, 04, 05, 07, 08, 11 (регламент § 6). Первый шаг после ответа на ВП-52 — «шаг 0»: лист-образец и три экрана в двух направлениях облика (08 § 2.2).
