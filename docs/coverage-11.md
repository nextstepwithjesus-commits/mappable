# Покрытие родословных отрывков

Имя собственное считается сопоставленным, если оно совпадает с именем или иной формой лица, у которого есть ссылка на эту главу.
Итого: 57% имён сопоставлено (27 из 47).


## Чис 25:14-15 — 57% (4 из 7; тома 11)

Без лица: Симеонова (25:14); Оммофа (25:15); Мадиамского (25:15)

## Суд 8:29-32 — 80% (8 из 10; тома 11)

Без лица: Также (8:31); Офре (8:32)

## Суд 10:1-5 — 50% (7 из 14; тома 11)

Без лица: Иссахарова (10:1); Шамире (10:1, 10:2); Ефремовой (10:1); Галаада (10:3); Галаадской (10:4); Камоне (10:5)

## Суд 12:8-15 — 50% (8 из 16; тома 11)

Без лица: Завулонянин (12:11, 12:12); Завулоновой (12:12); Пирафонянин (12:13, 12:15); Пирафоне (12:15); Ефремовой (12:15); Амаликовой (12:15)
