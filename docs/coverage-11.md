# Покрытие родословных отрывков

Имя собственное считается сопоставленным, если оно совпадает с именем или иной формой лица, у которого есть ссылка на эту главу.
Итого: 66% имён сопоставлено (27 из 41).

Без лица: Симеонова (25:14); Оммофа (25:15); Мадиамского (25:15)

## Суд 8:29-32 — 80% (8 из 10; тома 11)

Без лица: Также (8:31); Офре (8:32)

## Суд 10:1-5 — 58% (7 из 12; тома 11)

Без лица: Иссахарова (10:1); Шамире (10:1, 10:2); Ефремовой (10:1); Камоне (10:5)
