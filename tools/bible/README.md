# Текст Синодального перевода (66 канонических книг)

`synodal.tsv` — Синодальный перевод Библии (1876, общественное достояние) в нумерации Синодального издания.
Формат строки: `книга<TAB>глава<TAB>стих<TAB>текст`, книга — стандартное сокращение (`Быт`, `1Цар`, `3Цар`, `1Пар`, `Мф` …).

Состав: только 66 канонических книг. Исключены неканонические книги Синодального издания и
неканонические добавления к Книге пророка Даниила (Дан 3:24–90, гл. 13–14). Добавления к Книге Есфирь
в Синодальном тексте заключены в квадратные скобки внутри стихов; валидатор не принимает их как основание для фактов
(текст в `[…]` при сверке имён игнорируется).

Источник текста: scrollmapper/bible_databases (`formats/json/RusSynodal.json`), преобразован скриптом.
Используется для: (1) проверки существования каждой ссылки; (2) сверки имени лица с текстом стиха;
(3) извлечения цитат, показываемых в карточках.

## Параллельные места TSK (справка, не факт; 11 § 4.12; источник `src-tsk`)

`tsk.tsv` — Treasury of Scripture Knowledge (модуль CrossWire SWORD «TSK» 1.4, `inputs/crosswire/TSK.zip`, общественное
достояние) в синодальной нумерации. Строка — группа мест к слову стиха, как в источнике: `книга глава стих` (синодальные),
`стих KJV` (адрес записи в TSK), `группа` (номер по порядку источника), `слово TSK` (английское слово KJV, подсказка),
`места` (синодальные адреса через «; » в порядке источника; `*marg:` и подобные — пометки источника), `источник`.
`tsk-quarantine.tsv` — пары без однозначного синодального стиха, с причиной; ближайшим стихом ничего не подменяется.
Собирает `python3 -I tools/bible/tsk.py` (проверка — `--check`); перевод — по обращённой таблице
`base/versification/synodal-kjv.json`. Пары не входят в факты, рёбра, тождества и Связи; тест — `tests/base-tsk.test.ts`.

`crosswire-rus.py` — сверка `synodal.tsv` и `brackets.tsv` с модулем CrossWire RusSynodal (`inputs/crosswire/RusSynodal.zip`);
ничего не пишет (АФ-2).
