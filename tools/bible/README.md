# Текст Синодального перевода (66 канонических книг)

`synodal.tsv` — Синодальный перевод Библии (1876, общественное достояние) в нумерации Синодального издания.
Формат строки: `книга<TAB>глава<TAB>стих<TAB>текст`, книга — стандартное сокращение (`Быт`, `1Цар`, `3Цар`, `1Пар`, `Мф` …).

Состав: только 66 канонических книг. Исключены неканонические книги Синодального издания и
неканонические добавления к Книге пророка Даниила (Дан 3:24–90, гл. 13–14). Добавления к Книге Есфирь
в Синодальном тексте заключены в квадратные скобки внутри стихов; валидатор не принимает их как основание для фактов
(текст в `[…]` при сверке имён игнорируется).

Источник текста: scrollmapper/bible_databases (`formats/json/RusSynodal.json`), преобразован скриптом.
Используется для: (1) проверки существования каждой ссылки; (2) сверки имени лица с текстом стиха;
(3) извлечения цитат, показываемых в карточках.
