# Изображения лиц (решение 74)

Пока здесь нет файлов, карточки показывают условные силуэты (src/ui/tree/Avatar.tsx).

Как добавить изображение лица:

1. Файл — `<id>.webp` (можно `.jpg` или `.png`), где `<id>` — идентификатор лица в данных: `adam.webp`,
   `iosif-muzh-marii.webp`. Подсказка id: `npm run -s id -- "Иессей"`.
2. Размер — 256 × 256 px, квадрат, голова и плечи по центру; вес — до 30 КБ (webp, качество 75–80).
3. Больше ничего делать не нужно: сборка подхватывает файлы этой папки сама (`import.meta.glob` в Avatar.tsx),
   изображение встаёт вместо силуэта на карточке древа.

Помета обязательна и ставится автоматически: на изображении — «худож.», для подсказки и диктора — «Художественная
интерпретация создателей приложения, не изображение из Писания». Изображение не несёт фактов и не выдаётся за
слова Писания (ТЗ П-1, П-5): изображений лиц в Писании нет.
